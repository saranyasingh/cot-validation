RULE-2: If someone sees the cow then they are cold :: ∀x (Sees(x, cow) → Cold(x))
RULE-3: If someone is cold then they like the rabbit :: ∀x (Cold(x) → Likes(x, rabbit))
RULE-4: If someone needs the bear then the bear is young :: ∀x (Needs(x, bear) → Young(bear))
RULE-5: Young people are kind :: ∀x (Young(x) → Kind(x))
RULE-6: If someone is round then they like the mouse :: ∀x (Round(x) → Likes(x, mouse))
RULE-7: If someone likes the bear and they like the mouse then the bear likes the mouse :: ∀x ((Likes(x, bear) ∧ Likes(x, mouse)) → Likes(bear, mouse))

RULE-9: If someone is round and they do not need the bear then they see the rabbit :: ∀x ((Round(x) ∧ ¬Needs(x, bear)) → Sees(x, rabbit))
