To determine Josh's profit from flipping the house, we need to follow these steps:

**Premise 1:** Josh bought the house for $80,000.

**Premise 2:** Josh spent an additional $50,000 on repairs.

**Premise 3:** After repairs, the total cost was $80,000 + $50,000 = $130,000.

**Premise 4:** The increase in the value of the house due to repairs was 150%.

**Premise 5:** To find the original value before repairs, we use the formula for percentage increase: \( \text{Original Value} = \frac{\text{New Value}}{1 + \text{Percentage Increase}} \).

**Calculation:**
- New Value = $130,000
- Percentage Increase = 150% or 1.5 (as a decimal)

\[ \text{Original Value} = \frac{130,000}{1 + 1.5} = \frac{130,000}{2.5} = 52,000 \]

So, the original value of the house before any improvements was $52,000.

**Conclusion:**
The difference between the new value ($130,000) and the original value ($52,000) gives us the profit.

**Profit Calculation:**
\[ \text{Profit} = \text{New Value} - \text{Original Value} = 130,000 - 52,000 = 78,000 \]

Therefore, Josh made a profit of **$78,000** after selling the flipped house.
