To determine how many total meters James runs a week, we need to break down the problem into smaller steps.

**Step 1:** Calculate the distance James runs per sprint.
- James runs 60 meters each sprint.

**Step 2:** Determine the number of sprints per week.
- James runs 3 sprints each time.
- He runs this 3 times a week.

So, the total number of sprints per week = Number of sprints/time * Number of times per week
= 3 sprints/time * 3 times/week
= 9 sprints/week

**Step 3:** Calculate the total distance James runs per week.
- Distance per sprint = 60 meters
- Total sprints per week = 9

Therefore, the total distance James runs per week = Distance per sprint * Total sprints per week
= 60 meters/sprint * 9 sprints/week
= 540 meters/week

The answer is: 540
