To solve this problem, let's break it down step by step:

1. We know that Seattle has 20 sheep.
   - Let's denote Seattle's number of sheep as S = 20.

2. Charleston has 4 times as many sheep as Seattle.
   - So, Charleston's number of sheep (C) can be calculated as C = 4 * S = 4 * 20 = 80.

3. Toulouse has twice as many sheep as Charleston.
   - Therefore, Toulouse's number of sheep (T) can be calculated as T = 2 * C = 2 * 80 = 160.

4. To find the total number of sheep for all three cities combined, we add up their individual counts:
   - Total sheep = T + C + S = 160 + 80 + 20 = 260.

Therefore, the total number of sheep in Toulouse, Charleston, and Seattle is 260.

The answer is: 260
