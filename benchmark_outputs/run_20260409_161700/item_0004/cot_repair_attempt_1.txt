EXPLANATION

1. James runs 3 sprints each time he goes running.
2. He goes running 3 times a week.
3. Therefore, in one session, he runs \(3 \times 3 = 9\) sprints.
4. Each sprint is 60 meters long.
5. Thus, in one session, he runs \(9 \times 60 = 540\) meters.
6. Since he runs this once every week, over the course of a week, he would run \(540 \times 7 = 3780\) meters.

Therefore, the answer is: 3780
