To calculate the total number of meters James runs in a week, we need to multiply the distance he runs per sprint by the number of sprints and then by the number of times he runs each week.

Distance per sprint = 60 meters
Number of sprints = 3
Number of times per week = 3

Total distance per week = Distance per sprint × Number of sprints × Number of times per week
Total distance per week = 60 meters/sprint × 3 sprints × 3 times/week
Total distance per week = 180 meters × 3 times/week
Total distance per week = 540 meters
