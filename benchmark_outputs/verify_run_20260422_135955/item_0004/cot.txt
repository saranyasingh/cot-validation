Explanation:
1. James runs 3 sprints per session.
2. Each sprint is 60 meters long.
3. Therefore, each session consists of 3 * 60 = 180 meters.
4. James has sessions 3 times a week.
5. To find the total distance run in a week, we multiply the weekly sessions (3) by the distance per session (180 meters).
6. Thus, the total distance run in a week is 3 * 180 = 540 meters.

The answer is: 540
