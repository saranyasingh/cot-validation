EXPLANATION

1. Let's start by identifying the key information given in the problem.
   - In the first month, there were 60 downloads.

2. We need to calculate the number of downloads for the second month.
   - According to the problem, the number of downloads in the second month was three times as many as in the first month.
   - Therefore, we multiply 60 by 3 to find out how many downloads there were in the second month: \( 60 \times 3 = 180 \).

3. Next, we need to account for the reduction in the number of downloads in the third month.
   - The problem states that the number of downloads in the third month was reduced by 30% compared to the second month.
   - To find the actual number of downloads in the third month, we first determine what 30% of 180 is and subtract it from 180.
   - Calculate 30% of 180: \( 180 \times 0.30 = 54 \).
   - Subtract this value from 180 to get the actual number of downloads in the third month: \( 180 - 54 = 126 \).

4. Now, let's sum up all the downloads from the three months to find the total.
   - Add the number of downloads from the first, second, and third months: \( 60 + 180 + 126 = 366 \).

Therefore, the total number of downloads over the three months is 366. 

The answer is: 366.
