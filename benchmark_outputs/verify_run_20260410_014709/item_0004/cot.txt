To determine how many total meters James runs in a week, we need to break down the problem into smaller steps.

1. **Determine the distance James runs per sprint**: According to the information provided, James runs 60 meters each sprint.
   
2. **Determine the number of sprints James runs per session**: James runs 3 sprints each time he goes running.

3. **Calculate the total distance for one session**:
   - Distance per sprint = 60 meters
   - Number of sprints per session = 3
   
   Total distance for one session = \( 60 \text{ meters/sprint} \times 3 \text{ sprints/session} = 180 \text{ meters/session} \)

4. **Determine how often James runs** : James runs this routine 3 times a week.

5. **Calculate the total weekly distance**:
   - Total distance per session = 180 meters
   - Number of sessions per week = 3
   
   Total weekly distance = \( 180 \text{ meters/session} \times 3 \text{ sessions/week} = 540 \text{ meters/week} \)

Thus, based on these calculations, James runs a total of 540 meters a week.
