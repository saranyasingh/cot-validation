To determine how many total meters James runs in a week, we need to break down the problem into smaller steps and then sum up the results.

1. **Calculate the distance for one complete workout (one set of three sprints):**
   - Each sprint is 60 meters.
   - There are 3 sprints per session.
   - Therefore, the distance for one session (one set) is:
     \[
     3 \text{ sprints} \times 60 \text{ meters/sprint} = 180 \text{ meters}
     \]

2. **Determine the number of sessions per week:**
   - James runs 3 sprints 3 times a week.
   - Therefore, the number of sessions per week is:
     \[
     3 \text{ sprints/session} \times 3 \text{ sessions/week} = 9 \text{ sessions/week}
     \]

3. **Calculate the total distance run per week:**
   - Multiply the distance for one session by the number of sessions per week:
     \[
     180 \text{ meters/session} \times 9 \text{ sessions/week} = 1620 \text{ meters/week}
     \]

So, James runs a total of 1620 meters per week. The answer is: 1620
