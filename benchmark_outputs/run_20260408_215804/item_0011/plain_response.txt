To find out how many downloads the program had in total over the three months, we need to calculate the number of downloads for each month and then sum them up.

1. **First Month**: 
   - Downloads = 60

2. **Second Month**:
   - According to the problem, the number of downloads in the second month was three times as many as the downloads in the first month.
     \[
     \text{Downloads} = 3 \times 60 = 180
     \]

3. **Third Month**:
   - In the third month, the number of downloads reduced by 30% from the previous month's count.
     \[
     \text{Reduction} = 30\% \text{ of } 180 = 0.30 \times 180 = 54
     \]
   - Therefore, the actual number of downloads in the third month would be:
     \[
     \text{Downloads} = 180 - 54 = 126
     \]

Now, let's add up all the downloads:

- First Month: 60
- Second Month: 180
- Third Month: 126

Total Downloads = 60 + 180 + 126 = 366

Thus, the total number of downloads over the three months is 366. 

The answer is: 366
