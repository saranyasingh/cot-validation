To calculate Josh's profit from flipping the house, we need to follow these steps:

1. **Calculate the total cost of the house after repairs:**
   - Cost of the house: $80,000
   - Amount spent on repairs: $50,000
   - Total cost = $80,000 + $50,000 = $130,000

2. **Determine the increase in the house's value due to the renovations:**
   - The problem states that the value of the house increased by 150%.
   - Value increase percentage: 150%
   - Increase amount = 150% of $130,000 = 1.5 * $130,000 = $195,000

3. **Calculate the new value of the house after renovation:**
   - New value = Original value + Increase in value
   - New value = $130,000 + $195,000 = $325,000

4. **Calculate the profit:**
   - Profit = New value - Total cost
   - Profit = $325,000 - $130,000 = $195,000

Therefore, the profit Josh made from this house flip is $195,000.

The answer is: $195,000
