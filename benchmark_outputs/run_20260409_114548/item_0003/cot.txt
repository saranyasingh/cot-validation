EXPLANATION

To determine Josh's profit, we need to follow these steps:

1. **Calculate the total cost of buying the house including repairs**:  
   - Cost of the house = $80,000
   - Amount spent on repairs = $50,000
   - Total initial investment = $80,000 + $50,000 = $130,000

2. **Determine the increase in the value of the house due to renovations**:  
   - Increase in value = 150% of original value (since it was initially $80,000)
   - Value after renovation = Original value + (Original value * Percentage increase)  
     = $80,000 + ($80,000 * 1.5)  
     = $80,000 + $120,000  
     = $200,000

3. **Calculate the actual net worth after all expenses**:  
   - Net worth after renovations = Value after renovation - Initial investment  
     = $200,000 - $130,000  
     = $70,000

4. **Calculate the profit**:  
   - Profit = Net worth after renovations - Initial investment  
     = $70,000 - $130,000  
     = -$60,000

Therefore, Josh made a loss of $60,000.
