To find out how many total meters James runs in a week, we need to follow these steps:

1. Determine the number of sprints James runs per session.
2. Calculate the distance he runs during one session.
3. Multiply the distance of one session by the number of sessions per week.

Step 1: James runs 3 sprints each time he goes for a run.

Step 2: Each sprint is 60 meters long.
   Distance per session = Number of sprints × Distance per sprint
   Distance per session = 3 sprints × 60 meters/sprint
   Distance per session = 180 meters

Step 3: James runs this session 3 times a week.
   Total weekly distance = Distance per session × Number of sessions per week
   Total weekly distance = 180 meters/session × 3 sessions/week
   Total weekly distance = 540 meters

Therefore, the answer is: 540 meters.
