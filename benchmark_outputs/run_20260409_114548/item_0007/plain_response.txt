Let's break down the problem step by step:

1. We know that Seattle has 20 sheep.
   Let's denote this number as \( S = 20 \).

2. Charleston has 4 times as many sheep as Seattle.
   So, the number of sheep in Charleston (\( C \)) can be calculated as:
   \( C = 4 \times S = 4 \times 20 = 80 \).

3. Toulouse has twice as many sheep as Charleston.
   So, the number of sheep in Toulouse (\( T \)) can be calculated as:
   \( T = 2 \times C = 2 \times 80 = 160 \).

4. To find the total number of sheep for all three cities, we add up their numbers:
   Total sheep = \( S + C + T = 20 + 80 + 160 = 260 \).

Therefore, the total number of sheep in Toulouse, Charleston, and Seattle combined is 260.

The answer is: 260
