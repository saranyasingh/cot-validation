Premise 1: Josh buys a house for $80,000.
Premise 2: Josh spends $50,000 on repairs.
Premise 3: The repairs increase the value of the house by 150%.

Step 1: Calculate the total cost of the house including repairs.
- Total cost = Cost of house + Cost of repairs
- Total cost = $80,000 + $50,000 = $130,000

Step 2: Determine the new value of the house after repairs.
- The increase in value is 150% of the original value ($80,000).
- Increase in value = 150% * $80,000 = 1.5 * $80,000 = $120,000
- New value of the house = Original value + Increase in value
- New value of the house = $80,000 + $120,000 = $200,000

Step 3: Calculate the profit made by Josh.
- Profit = New value of the house - Total cost
- Profit = $200,000 - $130,000 = $70,000

The answer is: 70000
