EXPLANATION
1. The program had 60 downloads in the first month.
2. In the second month, the number of downloads was three times as many as the first month. Therefore, the number of downloads in the second month = 3 * 60 = 180.
3. In the third month, the downloads reduced by 30%. Thus, the number of downloads in the third month = 180 - (30% of 180) = 180 - (0.30 * 180) = 180 - 54 = 126.
4. To find the total number of downloads over the three months, we sum the downloads from each month: 60 + 180 + 126 = 366.

The answer is: 366
