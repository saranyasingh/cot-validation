To determine how many bags Frank can fill with 22 pieces of candy if each bag holds 11 pieces, we need to divide the total number of candies by the number of candies per bag.

Total candies = 22
Candies per bag = 11

Number of bags = Total candies / Candies per bag
Number of bags = 22 / 11
Number of bags = 2

Therefore, Frank would have 2 bags. 

The answer is: 2
