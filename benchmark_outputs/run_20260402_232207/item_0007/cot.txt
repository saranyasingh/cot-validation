**Logical Syllogism**

1. **Premise 1:** Randy has 95 blocks.
   - This establishes the total number of blocks available to Randy.

2. **Premise 2:** Randy uses 20 blocks to build a house.
   - This specifies the number of blocks used for building the first structure (house).

3. **Premise 3:** Randy uses 50 blocks to build a tower.
   - This specifies the number of blocks used for building the second structure (tower).

4. **Premise 4:** To determine how many more blocks were used to build the tower than the house, we need to subtract the number of blocks used for the house from the number of blocks used for the tower.
   - Let \( B \) represent the blocks used for the house.
   - Let \( T \) represent the blocks used for the tower.
   - Therefore, \( B = 20 \) and \( T = 50 \).
   
5. **Premise 5:** Calculate the difference between the blocks used for the tower and the blocks used for the house.
   - \( \text{Difference} = T - B \)
   - Substitute the values: \( \text{Difference} = 50 - 20 \)

6. **Conclusion:** 
   - After performing the subtraction, we find that:
     \[
     50 - 20 = 30
     \]

Therefore, the answer is: The answer is: 30.
