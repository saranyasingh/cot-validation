To find out how many seats the Ferris wheel has, we need to divide the total number of people that can ride the wheel at once (which is 18) by the capacity of each seat (which is 9).

So,
Number of seats = Total number of people / Capacity per seat

Plugging in the numbers:
Number of seats = 18 / 9

Now let's calculate this:

Number of seats = 2

Therefore, the answer is: 2.
