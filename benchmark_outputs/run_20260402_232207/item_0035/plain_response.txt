To determine the total number of books in the 'crazy silly school' series, we can add the number of books already read (13) to the number of books still left to be read (8).

Calculation:
\[ \text{Total number of books} = \text{Books already read} + \text{Books still left to be read} \]
\[ \text{Total number of books} = 13 + 8 \]
\[ \text{Total number of books} = 21 \]

Therefore, the answer is: 21.
