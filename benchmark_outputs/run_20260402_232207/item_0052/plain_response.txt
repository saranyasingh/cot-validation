To determine how many apples the chef used, we start with the initial number of apples and subtract the number of apples left after making the pies.

Initial number of apples = 40
Number of apples left = 39

Number of apples used = Initial number of apples - Number of apples left
                         = 40 - 39
                         = 1

Therefore, the chef used 1 apple. The answer is: 1.
