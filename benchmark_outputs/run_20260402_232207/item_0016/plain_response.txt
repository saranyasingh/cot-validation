To determine how many rows Faye can make, we need to follow these steps:

1. Calculate the total number of pencils Faye has.
2. Determine how many rows can be made with the total number of pencils, given that there are 2 pencils per row.

Faye has 35 packs of pencils, and each pack contains 4 pencils. So, the total number of pencils is:
\[ 35 \text{ packs} \times 4 \text{ pencils/pack} = 140 \text{ pencils} \]

Step 2: Determine how many rows can be made.
If each row contains 2 pencils, then the number of rows that can be made from 140 pencils is:
\[ 140 \text{ pencils} \div 2 \text{ pencils/row} = 70 \text{ rows} \]

Therefore, Faye can make 70 rows of pencils.
