Let's convert the chain-of-thought reasoning into structured First-Order Logic (FOL):

### FACTS
```plaintext
FACT-1: There are eight bird families living near a mountain. :: BirdsNearMountain(8).
```

### RULES
```plaintext
RULE-1: If a family flies away, they fly to a certain location. :: FlyingAway(Family, Location).
```

### INFERENCES
```plaintext
INF-1: Calculate the total number of bird families that flew away. :: TotalFlyAway = BirdsNearMountain(8) + BirdsNearMountain(14) + BirdsNearMountain(31).
INF-2: Determine how many more bird families flew to Africa compared to Asia. :: MoreToAfrica = BirdsNearMountain(42) - BirdsNearMountain(31).
```

Now let's break down each inference step-by-step:

#### INF-1: Calculate the total number of bird families that flew away.
- Let \( B_{\text{near\_mountain}} \) represent the number of bird families living near the mountain.
- Let \( B_{\text{near\_africa}} \) represent the number of bird families flying to Africa.
- Let \( B_{\text{near\_asia}} \) represent the number of bird families flying to Asia.

From Premises:
\[ B_{\text{near\_mountain}} = 8 \]
\[ B_{\text{near\_africa}} = 42 \]
\[ B_{\text{near\_asia}} = 31 \]

Total number of bird families that flew away:
\[ \text{TotalFlyAway} = B_{\text{near\_mountain}} + B_{\text{near\_africa}} + B_{\text{near\_asia}} \]
\[ \text{TotalFlyAway} = 8 + 42 + 31 \]
\[ \text{TotalFlyAway} = 81 \]

So,
\[ \text{TotalFlyAway} = 81 \]

#### INF-2: Determine how many more bird families flew to Africa compared to Asia.
- Let \( F_{\text{to\_africa}} \) represent the number of bird families flying to Africa.
- Let \( F_{\text{to\_asia}} \) represent the number of bird families flying to Asia.

From Premises:
\[ F_{\text{to\_africa}} = 42 \]
\[ F_{\text{to\_asia}} = 31 \]

Difference in the number of bird families flying to Africa compared to Asia:
\[ \text{MoreToAfrica} = F_{\text{to\_africa}} - F_{\text{to\_asia}} \]
\[ \text{MoreToAfrica} = 42 - 31 \]
\[ \text{MoreToAfrica} = 11 \]

So,
\[ \text{MoreToAfrica} = 11 \]
