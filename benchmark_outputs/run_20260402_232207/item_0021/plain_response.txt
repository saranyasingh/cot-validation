To determine how many days it took to harvest the oranges, we need to divide the total number of sacks by the number of sacks harvested per day.

Total sacks of oranges = 54
Sacks harvested per day = 18

Number of days = Total sacks / Sacks per day
Number of days = 54 / 18
Number of days = 3

Therefore, it took 3 days to harvest all the oranges.
