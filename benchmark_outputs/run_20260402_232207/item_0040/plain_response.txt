To determine how many cakes each person ate, we need to follow these steps:

1. Calculate the total number of crackers given away.
2. Determine how many crackers each friend received.
3. Since the problem states that the crackers and cakes were given equally, divide the number of cakes by 2 to find out how many cakes each friend got.

First, let's calculate the total number of crackers given away:
\[ \text{Total crackers} = 29 \]

Since the crackers were given equally between 2 friends, each friend gets half of the crackers:
\[ \text{Crackers per friend} = \frac{29}{2} = 14.5 \]

Next, since the same amount of cakes was given to each friend, each friend also gets half of the cakes:
\[ \text{Cakes per friend} = \frac{30}{2} = 15 \]

Therefore, each person ate 15 cakes.

The answer is: 15
