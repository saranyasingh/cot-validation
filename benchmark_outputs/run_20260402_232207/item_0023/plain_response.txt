To determine how many more trees died in the typhoon compared to those that survived, we need to follow these steps:

1. Identify the number of trees that died.
2. Identify the initial number of trees grown.
3. Calculate the difference between the number of trees that died and the number of trees that survived.

Given:
- Trees that died = 13
- Initial number of trees grown = 3

Step-by-step calculation:
1. Number of trees that died = 13
2. Number of trees that survived = Total number of trees - Trees that died = 3 + (Total number of trees - 13)
   Since no specific total number of trees is given, we assume the initial number includes both dead and surviving ones.
   
However, if we consider only the trees that died as part of the initial count:
- Survived trees = 3
- Died trees = 13

Difference:
- Difference = Died trees - Survived trees = 13 - 3 = 10

Therefore, the number of additional trees that died in the typhoon compared to those that survived is 10.

The answer is: 10
