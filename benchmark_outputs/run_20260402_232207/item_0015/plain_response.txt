To find out how many points Melissa scored in each game, we can use the formula:

\[
\text{Points per game} = \frac{\text{Total points}}{\text{Number of games}}
\]

Given that Melissa scored a total of 91 points in 13 games, we substitute these values into the formula:

\[
\text{Points per game} = \frac{91}{13}
\]

Now, let's perform the division to find the number of points per game:

\[
\frac{91}{13} = 7
\]

So, Melissa scored 7 points in each game.

The answer is: 7
