Let's break down this problem into a logical syllogism:

1. **Premise 1:** Zachary did 44 push-ups.
   - This is our starting point, and it tells us how many push-ups Zachary completed.

2. **Premise 2:** David did 58 more push-ups than Zachary.
   - This statement gives us information about the relationship between the number of push-ups Zachary and David did. It specifies that David did an additional amount compared to Zachary.

3. **Premise 3:** To find out how many push-ups David did, we need to add 58 to the number of push-ups Zachary did.
   - This directly applies Premise 2 to calculate the total number of push-ups David did.

Now, let's apply these premises to calculate the total number of push-ups they both did together:

- Start with the number of push-ups Zachary did:
  \[
  \text{Number of push-ups Zachary did} = 44
  \]

- Add the extra push-ups David did over Zachary:
  \[
  \text{Total push-ups David did} = 44 + 58 = 102
  \]

- Now, sum up the total push-ups done by both:
  \[
  \text{Total push-ups Zachary and David did together} = 44 + 102 = 146
  \]

Therefore, the answer is: The total number of push-ups Zachary and David did altogether is 146.
