To find out how many push-ups Zachary and David did altogether, we need to follow these steps:

1. Determine how many push-ups David did.
2. Add the number of push-ups Zachary did to the number of push-ups David did.

Step 1: Calculate the number of push-ups David did.
David did 58 more push-ups than Zachary. Since Zachary did 44 push-ups:
\[ \text{Number of push-ups David did} = 44 + 58 \]

Step 2: Perform the addition.
\[ 44 + 58 = 102 \]
So, David did 102 push-ups.

Step 3: Add the number of push-ups Zachary did to the number of push-ups David did.
\[ \text{Total number of push-ups} = 44 + 102 \]

Step 4: Perform the addition again for clarity.
\[ 44 + 102 = 146 \]

Therefore, the total number of push-ups that Zachary and David did together is 146.
