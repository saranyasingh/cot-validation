To find out how many books are in each bookshelf when Bryan distributes 34 books equally between 2 bookshelves, we can use simple division:

Total number of books = 34
Number of bookshelves = 2

Each bookshelf would have:
\[ \text{Books per shelf} = \frac{\text{Total number of books}}{\text{Number of shelves}} = \frac{34}{2} = 17 \]

Therefore, the answer is: 17.
