To determine how many pages are in each chapter, we can follow these steps:

1. **Calculate the total number of pages per day**: 
   Since it takes Frank 607 days to finish the entire book and there are 594 pages in total, we divide the total number of pages by the number of days:
   \[
   \text{Pages per day} = \frac{\text{Total pages}}{\text{Days taken}} = \frac{594}{607}
   \]

2. **Simplify the fraction**:
   Performing the division gives us approximately:
   \[
   \frac{594}{607} \approx 0.981
   \]
   This means that Frank reads about 0.981 pages per day on average.

3. **Determine the number of pages per chapter**:
   Since each chapter contains an equal number of pages and there are 3 chapters, we multiply the daily page count by 3:
   \[
   \text{Pages per chapter} = \text{Pages per day} \times 3 = 0.981 \times 3
   \]

4. **Perform the multiplication**:
   \[
   0.981 \times 3 = 2.943
   \]

Therefore, each chapter contains approximately 2.943 pages.

The answer is: 2.943
