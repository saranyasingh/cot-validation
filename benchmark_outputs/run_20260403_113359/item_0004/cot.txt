Let's break down this problem using a logical syllogism:

1. **Premise 1:** James decides to run 3 sprints 3 times a week.
   - This establishes that there is a frequency and duration associated with his running schedule.

2. **Premise 2:** Each sprint consists of 60 meters.
   - This provides the distance covered per individual sprint.

3. **Conclusion:** To find out how many total meters James runs in a week, we need to multiply the number of sprints (which is 3) by the length of each sprint (which is 60 meters).

**Logical Reasoning:**
- From Premise 1, we know that James runs 3 sprints per session.
- From Premise 2, we know that each sprint covers 60 meters.
- Therefore, if we multiply the number of sprints (3) by the distance of each sprint (60 meters), we get the total distance covered in a single session.

4. **Calculation:**
   \[
   \text{Total meters per session} = 3 \times 60 = 180 \text{ meters}
   \]

5. **Final Answer:**
   - Since James runs 3 sessions a week, the total meters he runs in a week would be:
     \[
     \text{Total meters per week} = 180 \times 3 = 540 \text{ meters}
     \]
   
Therefore, the answer is: 540 meters.
