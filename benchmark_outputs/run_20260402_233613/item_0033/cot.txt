To determine the number of houses in a block based on the given information, we can use the following logical syllogism:

**Premise 1:** Each house receives 2 junk mails.
- This states that the total number of junk mails per house is 2.

**Premise 2:** The mailman has to give out 14 pieces of junk mail to each block.
- This establishes the total number of junk mails distributed across all blocks as 14.

**Conclusion:** To find the number of houses in a block, we need to divide the total number of junk mails (14) by the number of junk mails per house (2).

**Logical Syllogism:**
1. **Given:** Each house gets 2 junk mails.
   - Premise 1: Each house = 2 junk mails.
   
2. **Given:** There are 14 pieces of junk mail in total.
   - Premise 2: Total junk mails = 14.

3. **Calculation:** Divide the total number of junk mails by the number of junk mails per house.
   - Calculation: \( \frac{14}{2} = 7 \).

Therefore, the conclusion is:
The number of houses in a block is 7.

**Answer:** The answer is: 7 houses.
