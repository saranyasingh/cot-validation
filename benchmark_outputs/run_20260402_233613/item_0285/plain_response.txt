To determine the total number of green peaches in all the baskets, we need to follow these steps:

1. Identify the number of green peaches in one basket.
2. Multiply this number by the total number of baskets.

From the problem statement:
- Each basket contains 2 green peaches.
- There are 7 baskets in total.

Now, let's calculate the total number of green peaches:

\[ \text{Total green peaches} = (\text{Number of green peaches per basket}) \times (\text{Total number of baskets}) \]
\[ \text{Total green peaches} = 2 \times 7 \]
\[ \text{Total green peaches} = 14 \]

Therefore, the total number of green peaches in the baskets altogether is 14. The answer is: 14.
