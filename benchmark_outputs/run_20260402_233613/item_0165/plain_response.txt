To find the width of Jesse's room, we can use the formula for the area of a rectangle:

\[ \text{Area} = \text{Length} \times \text{Width} \]

Given:
- Area = 10 square feet
- Length = 5 feet

We need to find the Width (W). Rearranging the formula to solve for Width gives us:

\[ W = \frac{\text{Area}}{\text{Length}} \]

Substituting the given values:

\[ W = \frac{10}{5} = 2 \]

Therefore, the width of Jesse's room is 2 feet. The answer is: 2.
