Let's break down this problem into a logical syllogism:

**Premise 1:** There are 3 red peaches in the basket.
- This establishes our starting point with respect to the number of red peaches.

**Premise 2:** There are 10 more green peaches than red peaches in the basket.
- This tells us how many green peaches we need to find out based on the relationship between the number of red and green peaches.

**Conclusion:** Therefore, if there are 3 red peaches, then the total number of green peaches must be \(3 + 10 = 13\).

The answer is: 13.
