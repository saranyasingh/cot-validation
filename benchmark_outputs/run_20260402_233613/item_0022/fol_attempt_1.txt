Let's convert the given chain-of-thought reasoning into structured First-Order Logic (FOL). We will break down each step and express it using appropriate FOL symbols.

### Facts
These are direct statements derived from the given information without any logical rules.

```plaintext
FACT-1: Zachary did 46 push-ups :: PushUp(zachary, 46)
```

### Rules
These are universal quantifications that represent general principles or assumptions about the situation.

```plaintext
RULE-1: If someone does a certain number of push-ups, they also do a specific number of crunches :: ∀p (PushUp(p) → Crunches(p))
```

### Inferences
These are conclusions drawn based on the facts and rules provided. They must cite their premises.

```plaintext
INF-1: Since Zachary did 46 push-ups, he also did 58 crunches :: Crunches(zachary)
INF-2: Therefore, the difference between the number of crunches and push-ups Zachary did is 12 :: Difference(58, 46) = 12
```
