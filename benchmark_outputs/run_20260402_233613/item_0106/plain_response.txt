To determine how many drums of grapes would be filled per day, we need to divide the total number of drums by the number of days it takes to fill them.

Given:
- Total number of drums = 90
- Number of days = 6

We can calculate the number of drums filled per day as follows:

\[
\text{Drums per day} = \frac{\text{Total number of drums}}{\text{Number of days}}
\]

Substituting the given values:

\[
\text{Drums per day} = \frac{90}{6}
\]

\[
\text{Drums per day} = 15
\]

Therefore, the answer is: 15 drums per day.
