To determine how many bananas are in each group when they are organized into 2 groups, we need to divide the total number of bananas by the number of groups:

Total number of bananas = 290
Number of groups = 2

Bananas per group = Total number of bananas / Number of groups
Bananas per group = 290 / 2
Bananas per group = 145

Therefore, the answer is: 145.
