To find out how many pupils are in the school, we need to add the number of girls, boys, and teachers together.

Number of girls = 308
Number of boys = 318
Number of teachers = 36

Total number of pupils = Number of girls + Number of boys + Number of teachers

Total number of pupils = 308 + 318 + 36
                      = 626 + 36
