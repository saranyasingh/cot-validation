To solve this problem logically, let's break it down into clear steps:

1. **Identify the total number of books Bryan has:** 
   - We know that Bryan has 34 books.

2. **Determine how these books are distributed among the bookshelves:**
   - Bryan distributes these books equally across 2 bookshelves.

3. **Calculate the number of books per shelf:**
   - To find out how many books are on each bookshelf, we need to divide the total number of books (34) by the number of bookshelves (2).

Let's perform the division:
\[ \text{Number of books per shelf} = \frac{\text{Total number of books}}{\text{Number of shelves}} \]
\[ \text{Number of books per shelf} = \frac{34}{2} \]

Now, calculate the result:
\[ \text{Number of books per shelf} = 17 \]

So, the final answer is: Each bookshelf contains 17 books.
