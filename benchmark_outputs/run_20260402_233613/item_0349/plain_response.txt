To determine how many crackers each friend ate, we need to follow these steps:

1. Identify the total number of crackers Matthew initially had.
   - Matthew started with 23 crackers.

2. Determine how many crackers were given away.
   - After giving some crackers to his friends, Matthew has 11 crackers left.

3. Calculate the number of crackers given away.
   - The number of crackers given away = Initial number of crackers - Number of crackers left
     \[
     \text{Number of crackers given away} = 23 - 11 = 12
     \]

4. Since Matthew gave an equal number of crackers to both friends, divide the total number of crackers given away by 2.
   - Each friend received \(\frac{12}{2} = 6\) crackers.

Therefore, each friend ate 6 crackers.

The answer is: 6
