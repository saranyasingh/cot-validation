To determine how many pencils Faye placed in each row, we need to divide the total number of pencils by the number of rows.

Given:
- Total number of pencils = 12
- Number of rows = 3

We use the division operation:

\[ \text{Number of pencils per row} = \frac{\text{Total number of pencils}}{\text{Number of rows}} \]

Substituting the given values:

\[ \text{Number of pencils per row} = \frac{12}{3} \]

Performing the division:

\[ \frac{12}{3} = 4 \]

Therefore, the answer is: 4.
