To find out how many oranges are harvested per day, we need to multiply the number of sacks harvested per day by the number of oranges in each sack.

Number of sacks per day = 66
Number of oranges per sack = 28

Total number of oranges per day = Number of sacks per day × Number of oranges per sack

Total number of oranges per day = 66 × 28

Now let's calculate this:

\[ \text{Total number of oranges per day} = 66 \times 28 \]

Using a calculator or long multiplication:

\[ 66 \times 28 = 1848 \]

So, the total number of oranges harvested per day is 1848.

Therefore, the answer is: 1848
