1. **Premise 1:** "They harvest 66 sacks per day."
   - This statement directly provides us with the number of sacks being harvested daily.
   
2. **Premise 2:** "Each sack contains 28 oranges."
   - This statement gives us the number of oranges contained within each sack.
   
3. **Conclusion:** "Therefore, they harvest \(66 \times 28\) oranges per day."
   - To find the total number of oranges harvested per day, we multiply the number of sacks (66) by the number of oranges per sack (28).
   
4. **Calculation:**
   \[
   66 \times 28 = 1848
   \]
   - Therefore, they harvest 1848 oranges per day.

**The answer is:** 1848
