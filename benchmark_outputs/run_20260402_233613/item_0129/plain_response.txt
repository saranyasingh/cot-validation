To find out how many roses were originally in the vase, we can set up an equation based on the information given:

Let's denote the original number of roses as \( x \).

According to the problem:
- Jessica added 16 more roses.
- After adding these, there are now 23 roses in total.

This gives us the equation:
\[ x + 16 = 23 \]

To solve for \( x \), we subtract 16 from both sides of the equation:
\[ x + 16 - 16 = 23 - 16 \]
\[ x = 7 \]

So, there were initially 7 roses in the vase.

The answer is: 7
