**FACT-1:** Jessica added 16 roses to the vase. :: \( \text{JessicaAdded(16)} \)

**FACT-2:** After adding these roses, there were 23 roses in total. :: \( \text{TotalRosesAfterAdding(23)} \)

**FACT-3:** Let \( x \) be the number of roses originally in the vase before Jessica added any more. :: \( x \)

**FACT-4:** Equation representing the situation: \( x + 16 = 23 \). :: \( \text{x + 16 = 23} \)

**RULE-1:** Solve for \( x \): Subtract 16 from both sides. :: \( \forall x (x + 16 = 23 \rightarrow x = 7) \)

**INF-1:** The original number of roses in the vase was 7. :: \( \text{OriginalRoses(7)} \)
