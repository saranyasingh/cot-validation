Let's break down the problem into a logical syllogism:

**Premise 1:** Jessica added 16 roses to the vase.
- This means that after adding these roses, there were 23 roses in total.

**Premise 2:** If we let \( x \) be the number of roses originally in the vase before Jessica added any more, then the equation representing this situation would be:
\[ x + 16 = 23 \]

**Premise 3:** To find out how many roses were originally in the vase, we need to solve this equation for \( x \).
- We do this by subtracting 16 from both sides of the equation:
\[ x + 16 - 16 = 23 - 16 \]
- Simplifying this gives us:
\[ x = 7 \]

Therefore, the answer is: The original number of roses in the vase was 7.
