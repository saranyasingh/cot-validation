To determine how many more balloons Allan had compared to Jake, we need to follow these steps:

1. Identify the number of balloons each person brought.
   - Allan brought 5 balloons.
   - Jake brought 3 balloons.

2. Subtract the number of balloons Jake brought from the number of balloons Allan brought.
   \[

   \]
