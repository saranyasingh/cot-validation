1. **Premise**: Randy starts with 97 blocks.
   - This establishes the initial quantity of blocks available.

2. **Premise**: After building the tower, Randy has 72 blocks left.
   - This indicates that the number of blocks used to build the tower is subtracted from the total number of blocks Randy started with.

3. **Logical Reasoning**:
   - Let \( x \) represent the number of blocks used to build the tower.
   - According to the premises, we have the equation:
     \[
     97 - x = 72
     \]
   - To find \( x \), we need to isolate it on one side of the equation.

4. **Solving the Equation**:
   - Subtract 72 from both sides of the equation to solve for \( x \):
     \[
     97 - 72 = x
     \]
   - Simplify the left-hand side:
     \[
     25 = x
     \]

Therefore, the number of blocks Randy used to build the tower is \( x = 25 \).

The answer is: 25
