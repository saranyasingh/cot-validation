To determine how many blocks Randy used to build the tower, we can follow these steps:

1. Start with the total number of blocks Randy had initially.
   \[
   \text{Total blocks} = 97
   \]

2. Subtract the number of blocks left after building the tower from the initial total.
   \[
   \text{Blocks used in the tower} = \text{Total blocks} - \text{Blocks left}
   \]

   \[
   \text{Blocks used in the tower} = 97 - 72
   \]
