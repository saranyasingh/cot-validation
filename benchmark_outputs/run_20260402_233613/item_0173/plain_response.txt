To determine how many houses are in a block given that the mailman distributes 5 pieces of junk mail per house and needs to deliver 25 pieces of junk mail per block, we can set up the following equation:

Number of houses = Total number of pieces of junk mail / Number of pieces of junk mail per house

Plugging in the numbers:

Number of houses = 25 / 5

Simplifying this:

Number of houses = 5

Therefore, there are 5 houses in a block. The answer is: 5.
