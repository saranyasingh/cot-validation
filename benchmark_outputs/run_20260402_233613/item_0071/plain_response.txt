To determine the size of each group of oranges, we need to divide the total number of oranges by the number of groups they are organized into.

Given:
- Total number of oranges = 356
- Number of groups of oranges = 178

We calculate the size of each group of oranges as follows:

\[
\text{Size of each group} = \frac{\text{Total number of oranges}}{\text{Number of groups}}
\]

Substituting the given values:

\[
\text{Size of each group} = \frac{356}{178}
\]

Performing the division:

\[
\text{Size of each group} = 2
\]

Therefore, the size of each group of oranges is 2. 

The answer is: 2
