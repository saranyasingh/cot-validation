Premise 1: Zachary did 51 push-ups.
Premise 2: David did 44 push-ups.
Premise 3: We need to find how many more push-ups Zachary did compared to David.

Theorem: To find out how many more push-ups Zachary did than David, we subtract the number of push-ups David did from the number of push-ups Zachary did.

Logical Syllogism:
1. Premise 1 states that Zachary did 51 push-ups.
   - This establishes the quantity of push-ups Zachary completed.
   
2. Premise 2 states that David did 44 push-ups.
   - This provides another quantity of push-ups that David completed.
   
3. According to Premise 3, we need to calculate the difference between these two quantities.
   - Subtracting 44 (David's total) from 51 (Zachary's total): 
     51 - 44 = 7
   
Therefore, the conclusion drawn from this logical process is:

The answer is: Zachary did 7 more push-ups than David.
