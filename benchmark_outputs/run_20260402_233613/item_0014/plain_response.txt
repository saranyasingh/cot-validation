Let's break down the problem step by step:

1. Initially, Jerry had 7 books.
2. He also had 3 action figures initially.
3. Later, he added 2 more action figures to the shelf.

Now, let's calculate:
- The total number of action figures now = Initial action figures + Added action figures = 3 + 2 = 5
- The difference between the number of books and action figures = Number of books - Total number of action figures = 7 - 5 = 2

Therefore, there were 2 more books than action figures on the shelf.

The answer is: 2
