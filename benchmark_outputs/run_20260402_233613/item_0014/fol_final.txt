FACT-1: Jerry originally had 7 books :: BookCount(Jerry) = 7
FACT-2: Jerry originally had 3 action figures :: ActionFigureCount(Jerry) = 3

## RULES

INF-2: Difference between books and action figures :: BookCount(Jerry) - ActionFigureCount(Jerry) = 2
