To determine how many more pastries than cakes the baker sold, we need to subtract the number of cakes sold from the number of pastries sold:

Number of pastries sold = 92
Number of cakes sold = 68

Difference = Number of pastries sold - Number of cakes sold
           = 92 - 68
           = 24

Therefore, the baker sold 24 more pastries than cakes. The answer is: 24.
