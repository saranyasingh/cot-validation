To determine how many people each seat on the Ferris wheel can hold, we need to divide the total number of people that can ride at the same time by the number of seats available.

Given:
- Total number of people that can ride = 16
- Number of seats on the Ferris wheel = 4

We calculate the number of people per seat as follows:

\[ \text{People per seat} = \frac{\text{Total number of people}}{\text{Number of seats}} \]

\[ \text{People per seat} = \frac{16}{4} \]

\[ \text{People per seat} = 4 \]

Therefore, each seat on the Ferris wheel can hold 4 people. The answer is: 4.
