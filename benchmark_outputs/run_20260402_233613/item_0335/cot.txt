To determine how many boys are in the school, we need to follow these steps:

1. **Identify the total number of pupils**: 
   - Total number of pupils = 485

2. **Identify the number of girls**:
   - Number of girls = 232

3. **Calculate the number of boys**:
   - Since the total number of pupils includes both girls and boys, we subtract the number of girls from the total number of pupils.
   - Number of boys = Total number of pupils - Number of girls

Let's perform the calculation:

\[
\text{Number of boys} = 485 - 232
\]

Now, let's do the subtraction:

\[
485 - 232 = 253
\]

Therefore, the number of boys in the school is \( \boxed{253} \).
