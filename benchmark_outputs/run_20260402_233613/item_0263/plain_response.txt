To determine how many more pastries than cakes the baker made, we need to subtract the number of cakes sold from the number of pastries sold:

Number of pastries - Number of cakes = Difference

Given:
- Number of pastries made = 131
- Number of cakes made = 19
- Number of cakes sold = 70
- Number of pastries sold = 88

Subtracting these values gives us:

Difference = Pastries sold - Cakes sold
           = 88 - 70
           = 18

Therefore, the baker made 18 more pastries than cakes. The answer is: 18
