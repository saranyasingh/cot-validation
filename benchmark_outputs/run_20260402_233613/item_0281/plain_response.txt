To determine how many more sacks of unripe oranges than ripe oranges are harvested per day, we need to subtract the number of ripe oranges from the number of unripe oranges:

Number of unripe oranges = 71 sacks
Number of ripe oranges = 60 sacks

Difference in sacks = Number of unripe oranges - Number of ripe oranges
Difference in sacks = 71 - 60
Difference in sacks = 11 sacks

Therefore, the answer is: The difference between the amount of unripe oranges and ripe oranges harvested per day is 11 sacks.
