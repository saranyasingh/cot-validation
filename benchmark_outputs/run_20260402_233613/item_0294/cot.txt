Let's break down this problem into a logical syllogism:

**Premise 1:** Baker made 14 cakes.
- This establishes the total number of cakes available to be sold.

**Premise 2:** Baker made 153 pastries.
- This establishes the total number of pastries available to be sold.

**Premise 3:** Baker sold 8 pastries.
- This tells us how many pastries were actually sold.

**Premise 4:** Baker sold 97 cakes.
- This tells us how many cakes were actually sold.

Now, we need to determine:
**The difference between the number of cakes and pastries sold**

Step-by-step logical reasoning:

1. **Total Cakes Sold**: Baker sold 97 cakes.
   - Let \(C\) represent the number of cakes sold.
   - Therefore, \(C = 97\).

2. **Total Pastries Sold**: Baker sold 8 pastries.
   - Let \(P\) represent the number of pastries sold.
   - Therefore, \(P = 8\).

3. **Difference Between Cakes and Pastries Sold**:
   - To find out how many more cakes than pastries were sold, we subtract the number of pastries sold from the number of cakes sold.
   - Mathematically, this is represented as \(C - P\).
   
4. **Substitute the values**:
   - We substitute \(C = 97\) and \(P = 8\) into the equation \(C - P\):
     \[
     97 - 8
     \]

5. **Perform the subtraction**:
   - Calculate \(97 - 8\):
     \[
     97 - 8 = 89
     \]

Therefore, the baker sold 89 more cakes than pastries.

**Answer**: The baker sold 89 more cakes than pastries.
