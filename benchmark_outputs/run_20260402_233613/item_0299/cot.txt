Let's break down this problem using a logical syllogism:

1. Premise 1: There are initially 5 storks.
2. Premise 2: There are initially 3 birds.
3. Conclusion: When 4 more birds come to join them, we need to determine how many more birds there are compared to the number of storks.

To find out how many more birds than storks there are, let's calculate:
- Total initial number of birds = 3 + 4 (newly arrived birds) = 7 birds.
- Number of storks remains unchanged at 5.

Now, we compare the total number of birds to the number of storks:
- Difference = Total number of birds - Number of storks
- Difference = 7 - 5 = 2

Therefore, the conclusion drawn logically is that there are 2 more birds than storks sitting on the fence.

The answer is: 2
