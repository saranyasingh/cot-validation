To find out how many pages are in each chapter, we can divide the total number of pages by the number of chapters. 

Given:
- Total number of pages = 555
- Number of chapters = 5

We calculate as follows:

\[
\text{Pages per chapter} = \frac{\text{Total number of pages}}{\text{Number of chapters}}
\]

Substituting the given values:

\[
\text{Pages per chapter} = \frac{555}{5}
\]

Now let's perform the division:

\[
\text{Pages per chapter} = 111
\]

So, there are 111 pages in each chapter.

Therefore, the answer is: 111.
