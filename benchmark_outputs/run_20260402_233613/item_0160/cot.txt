To determine how many aquariums he had, we need to consider that each aquarium contains 2 saltwater animals. Given that the total number of saltwater animals is 40, we can set up an equation based on this information.

Let's denote the number of aquariums as \( n \). Since each aquarium holds 2 animals and there are 40 animals in total, we can write the following relationship:

\[ 2n = 40 \]

Next, we solve for \( n \) by dividing both sides of the equation by 2:

\[ n = \frac{40}{2} \]
\[ n = 20 \]

Thus, he had 20 aquariums.
