To determine how many chairs are on each table, we need to divide the total number of chairs by the number of tables. Here's the step-by-step reasoning:

1. The total number of chairs available is given as 12.
2. There are 2 sets of tables, and each set has an equal number of chairs.
3. To find out how many chairs are on each table, we divide the total number of chairs by the number of sets (or tables).

So, we calculate:
\[ \text{Number of chairs per table} = \frac{\text{Total number of chairs}}{\text{Number of tables}} \]
\[ \text{Number of chairs per table} = \frac{12}{2} \]
\[ \text{Number of chairs per table} = 6 \]

Therefore, there are 6 chairs for each table. The answer is: 6.
