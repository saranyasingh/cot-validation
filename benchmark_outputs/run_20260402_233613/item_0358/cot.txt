Premise 1: There are 2 sets of tables.
Premise 2: Each set has the same number of chairs.
Premise 3: Total number of chairs = 12.

To determine how many chairs are on each table:
- Let's denote the number of chairs per table as \( x \).
- Since there are 2 sets and each set has \( x \) chairs, we can express this mathematically as \( 2x \).

From Premise 3, we know that the total number of chairs is 12. Therefore,
\[ 2x = 12 \]

Solving for \( x \):
\[ x = \frac{12}{2} \]
\[ x = 6 \]

Therefore, the answer is: Each table has 6 chairs.
