To determine how many pastries the baker would still have after selling some, we need to follow these steps:

1. Calculate the total number of pastries initially made.
2. Subtract the number of pastries sold from the initial number of pastries.

Step 1: Initial number of pastries = 148

Step 2: Number of pastries sold = 103

Number of pastries remaining = Initial number of pastries - Number of pastries sold
= 148 - 103
= 45

Therefore, the answer is: The baker would still have 45 pastries.
