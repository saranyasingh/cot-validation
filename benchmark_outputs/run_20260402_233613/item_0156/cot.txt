Let's break down this problem using a logical syllogism:

1. **Premise 1:** Haley initially had 20 trees.
   - This establishes the starting point and total number of trees before any changes occur.

2. **Premise 2:** After the typhoon, 4 trees remained.
   - This indicates that the number of surviving trees after the event (the typhoon) equals 4.

3. **Logical Deduction:** To find out how many trees died during the typhoon, we need to subtract the number of remaining trees from the initial number of trees.
   
4. **Calculation:** 
   - Initial number of trees = 20
   - Number of surviving trees after the typhoon = 4
   
   Therefore,
   - Number of trees that died = Initial number of trees - Number of surviving trees
   - Number of trees that died = 20 - 4

5. **Final Answer:**  
   The number of trees that died in the typhoon is 16.
