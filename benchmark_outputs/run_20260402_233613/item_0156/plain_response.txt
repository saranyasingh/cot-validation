To determine how many trees died in the typhoon, we need to subtract the number of trees that survived from the initial number of trees.

Initial number of trees = 20
Number of trees remaining after the typhoon = 4

Number of trees that died = Initial number of trees - Number of trees remaining after the typhoon
Number of trees that died = 20 - 4
Number of trees that died = 16

Therefore, the answer is: 16.
