Premise 1:
If Baker's friend bought 137 cakes from him and if he had made 169 cakes initially, then the difference between what Baker has now (the number of cakes he sold) and what he initially had must equal the number of cakes he still has.

Premise 2:
The number of cakes Baker still has equals the initial number of cakes minus the number of cakes he sold.

Premise 3:
The number of cakes Baker sold is given as 137.

Premise 4:
The initial number of cakes Baker had is given as 169.

To find out how many cakes Baker still has, we need to calculate:

Final Calculation:
Initial number of cakes - Number of cakes sold = Number of cakes remaining
