To find out how many more cakes than pastries the baker sold, we need to subtract the number of pastries sold from the number of cakes sold.

Number of cakes sold = 158
Number of pastries sold = 147

Difference = Number of cakes sold - Number of pastries sold
          = 158 - 147
          = 11

Therefore, the baker sold 11 more cakes than pastries. 

The answer is: 11
