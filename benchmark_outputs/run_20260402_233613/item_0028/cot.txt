1. **Premise 1**: John will use 8 large planks of wood.
   - This is given directly and establishes the quantity needed for the first part of the calculation.

2. **Premise 2**: Each plank of wood requires 74 pieces of nails to be secured.
   - This provides the rate at which nails are required per plank, which will help us calculate the total number of nails needed if we know the number of planks.

3. **Logical Reasoning Step**:
   - To find out how many planks John needs, we multiply the number of planks by the number of nails per plank.
   - Therefore, \( \text{Total Nails} = \text{Number of Planks} \times \text{Nails per Plank} \).

4. **Substitution**:
   - From Premise 1, we have 8 planks.
   - From Premise 2, each plank requires 74 nails.
   - Substituting these values into our formula gives: \( \text{Total Nails} = 8 \times 74 \).

5. **Calculation**:
   - \( 8 \times 74 = 608 \) nails.

6. **Conclusion**:
   - Since the problem only asks about the number of planks used, not the total nails, we do not need to consider the nails separately because the nails were already factored into the original premise regarding planks.

Therefore, the answer is: The number of planks John needs for the house wall is 8.
