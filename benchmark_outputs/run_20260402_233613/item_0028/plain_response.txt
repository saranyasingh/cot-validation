To determine how many planks John needs for the house wall, we first need to calculate the total number of nails required for all the planks.

Given:
- Each plank requires 74 nails.
- He uses 8 planks in total.

We can find the total number of nails needed by multiplying the number of planks by the number of nails per plank:

\[ \text{Total nails} = \text{Number of planks} \times \text{Nails per plank} \]
\[ \text{Total nails} = 8 \times 74 \]

Now, let's perform the multiplication:

\[ 8 \times 74 = 592 \]

So, John needs 592 nails in total.

Since each plank already provides us with the information about the nails required (each plank requires 74 nails), and we have calculated that 592 nails are needed in total, it implies that each plank indeed meets the requirement.

Therefore, John needs **8** planks for the house wall. The answer is: 8.
