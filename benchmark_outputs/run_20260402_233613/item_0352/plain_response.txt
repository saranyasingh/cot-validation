To determine how many apples are on Rachel's tree now, let's follow these steps:

1. Initially, the tree had 4 apples.
2. Rachel picked 2 apples from the tree. This reduces the number of apples to:
   \[
   4 - 2 = 2
   \]
3. After picking the apples, 3 new apples grew on the tree. So we add these new apples to the remaining amount:
   \[
   2 + 3 = 5
   \]

Therefore, the total number of apples on the tree now is 5. 

The answer is: 5
