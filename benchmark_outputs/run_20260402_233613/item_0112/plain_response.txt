To determine how many planks John needs for the house wall, we can set up an equation based on the information given:

1. John uses 4 nails in total.
2. Each plank requires 2 pieces of nails to be secured.

Let \( P \) represent the number of planks needed. Since each plank requires 2 nails and there are 4 nails used in total, we can write the equation:
\[ 2P = 4 \]

Now, solve for \( P \):
\[ P = \frac{4}{2} \]
\[ P = 2 \]

Therefore, John needs 2 planks for the house wall. The answer is: 2.
