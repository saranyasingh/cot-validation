To determine how many more action figures than books Jerry has on his shelf, we need to follow these steps:

1. Identify the number of books Jerry initially had.
   - Jerry had 3 books.

2. Identify the initial number of action figures Jerry had.
   - Jerry had 4 action figures.

3. Determine the total number of action figures after adding more.
   - Jerry added 2 more action figures, so the new total is \(4 + 2 = 6\) action figures.

4. Calculate the difference between the number of action figures and the number of books.
   - The difference is \(6 - 3 = 3\).

Therefore, there are 3 more action figures than books on his shelf.
