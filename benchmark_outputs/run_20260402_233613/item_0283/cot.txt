Let's break down this problem using a logical syllogism:

1. **Premise 1:** Jerry originally had 3 books.
   - This establishes our starting point with respect to books.

2. **Premise 2:** Jerry initially had 4 action figures.
   - This provides us with the initial number of action figures available.

3. **Premise 3:** Jerry added 2 more action figures to the shelf later.
   - This introduces an additional element (action figures) that was not present before but was added at some unspecified time.

Now, let's combine these premises to form our conclusion about the difference between action figures and books on the shelf:

4. **Conclusion:** Since we know there are 4 action figures and 3 books, we need to determine how many more action figures there are compared to books.

To find out how many more action figures than books are on the shelf:
- Subtract the number of books from the number of action figures: \(4 - 3 = 1\).

Therefore, there is 1 more action figure than books on the shelf.
