To determine how many ripe apples were on the tree initially, we can follow these steps:

1. **Identify the total number of apples on the tree now**: The tree currently has 7 apples.

   - Let \( x \) be the initial number of apples on the tree.
   - Rachel picked 2 ripe apples, so the number of ripe apples decreases by 2.

     \[
     x - 2 = 7
     \]

   \[
