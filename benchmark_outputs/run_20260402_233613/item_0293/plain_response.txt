To find out how many cakes the baker sold, we can use the basic subtraction principle. 

We start with the total number of cakes Baker had initially and subtract the number of cakes he has left:

Total cakes - Cakes left = Cakes sold

Given:
- Total cakes = 54
- Cakes left = 13

Now perform the calculation:

54 - 13 = 41

So, the baker sold 41 cakes. The answer is: 41
