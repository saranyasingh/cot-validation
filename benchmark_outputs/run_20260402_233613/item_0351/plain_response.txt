To determine how many more crayons than erasers Paul had left, we need to follow these steps:

1. Calculate the number of crayons Paul has left.
2. Compare the number of crayons and erasers he has left.

Step 1: Calculate the number of crayons Paul has left.
Paul started with 531 crayons and ended up with 391 crayons. Therefore, the number of crayons he has left is:
\[ 531 - 391 = 140 \]

Step 2: Compare the number of crayons and erasers he has left.
Paul has 140 crayons and 38 erasers left. To find out how many more crayons than erasers he has, we subtract the number of erasers from the number of crayons:
\[ 140 - 38 = 102 \]

Therefore, Paul has 102 more crayons than erasers left.

The answer is: 102
