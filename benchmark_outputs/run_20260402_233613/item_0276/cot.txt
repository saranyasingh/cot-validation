Let's break down this problem into a series of logical steps:

1. **Premise 1:** Each necklace requires 5 beads.
   - This establishes that we need to calculate based on the number of beads per necklace.

2. **Premise 2:** Emily made 4 necklaces.
   - This tells us how many items (necklaces) we're dealing with.

3. **Conclusion:** To find out how many beads Emily has used in total, we multiply the number of necklaces by the number of beads required per necklace.
   
4. **Calculation:** 
   \[
   \text{Total Beads} = \text{Number of Necklaces} \times \text{Beads Per Necklace}
   \]
   Substituting the given values:
   \[
   \text{Total Beads} = 4 \times 5 = 20
   \]

Therefore, the answer is: 20 beads.
