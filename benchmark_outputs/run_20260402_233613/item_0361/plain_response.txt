To find out how many more blocks Randy used to build the house compared to the tower, we need to subtract the number of blocks used for the tower from the number of blocks used for the house:

Number of blocks used for the house = 82
Number of blocks used for the tower = 79

Difference in blocks used = Number of blocks used for the house - Number of blocks used for the tower
                             = 82 - 79
                             = 3

Therefore, Randy used 3 more blocks to build the house than he did to build the tower. The answer is: 3.
