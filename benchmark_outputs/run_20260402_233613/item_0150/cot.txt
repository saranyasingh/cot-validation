Let's break down this problem using a logical syllogism:

Premise 1: Most animals migrate back to cooler countries during summer.
Premise 2: There are currently 87 bird families living near a mountain.
Premise 3: 18 new bird families have joined these families.

We need to determine how many bird families live near the mountain after the new ones join.

**Logical Syllogism:**

- **Major Premise:** All birds that migrate back to cooler countries do so during summer.
- **Minor Premise:** Birds near a mountain are considered birds that migrate back to cooler countries during summer.
- **Conclusion:** Therefore, there must be some number of bird families near the mountain before the migration, which we know is 87.

Now let’s add the new members:

- Initial count (before joining): 87 bird families.
- Number of new families joined: 18.

Using addition:
\[ \text{Total bird families now} = 87 + 18 \]

Calculating:
\[ 87 + 18 = 105 \]

Thus, the total number of bird families living near the mountain now is \( 105 \).

The answer is: 105.
