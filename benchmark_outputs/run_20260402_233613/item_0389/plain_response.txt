To determine how many rows Faye can make with 30 pencils, given that each row contains 5 pencils, we need to perform division.

1. **Identify the total number of pencils**: 
   - Total pencils = 30

2. **Determine the number of pencils per row**:
   - Pencils per row = 5

3. **Calculate the number of rows**:
   - Number of rows = Total pencils ÷ Pencils per row
   - Number of rows = 30 ÷ 5

4. **Perform the division**:
   - 30 ÷ 5 = 6

Therefore, Faye can make 6 rows of pencils.

The answer is: 6
