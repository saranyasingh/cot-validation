To find out how many bananas are in each group, we need to divide the total number of bananas by the number of groups they are organized into:

Total number of bananas = 203
Number of groups for bananas = 7

Bananas per group = Total number of bananas / Number of groups for bananas
= 203 / 7
= 29

Therefore, each group of bananas contains 29 bananas.

The answer is: 29
