1. **Premise**: The grocery store has three types of sodas: regular soda, diet soda, and lite soda.
   - This is our starting point, establishing that we're dealing with different categories of beverages.

2. **Premise**: We know the quantities of each type of soda:
   - Regular soda: 57 bottles
   - Diet soda: 26 bottles
   - Lite soda: 27 bottles

3. **Premise**: To find the total number of bottles, we need to add these numbers together.
   - This is the core operation required to solve the problem, combining all the information provided about the individual quantities.

4. **Logical Conclusion**:
   - Total bottles = (Regular soda) + (Diet soda) + (Lite soda)
   - Substituting the given values into this equation gives us:
     \[
     \text{Total bottles} = 57 + 26 + 27
     \]

5. **Calculation**:
   - Adding these numbers step-by-step:
     \[
     57 + 26 = 83
     \]
     \[
     83 + 27 = 110
     \]

Therefore, the answer is: 110 bottles.
