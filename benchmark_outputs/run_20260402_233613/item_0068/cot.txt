To determine the number of boys in the school, we need to follow these steps:

1. **Identify the total number of students**:
   - There are 697 girls.
   - Let \( B \) represent the number of boys.
   
   According to the problem, the total number of students (girls + boys) is:
   \[
   697 + B = \text{Total Number of Students}
   \]

2. **Express the relationship between girls and boys**:
   - We know that there are 228 more girls than boys.
   - This means if we subtract the number of boys from the number of girls, we get 228.
   \[
   697 - B = 228
   \]

3. **Solve for \( B \)**:
   - To find \( B \), add 228 to both sides of the equation:
   \[
   697 - B + B = 228 + B
   \]
   \[
   697 = 228 + B
   \]
   - Subtract 228 from both sides:
   \[
   697 - 228 = B
   \]
   \[
   469 = B
   \]

Therefore, the number of boys in the school is 469.

The answer is: 469
