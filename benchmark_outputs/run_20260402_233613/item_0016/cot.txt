1. **Premise 1:** Faye has 35 packs of pencils.
   - This establishes the total number of packs and implies that there are multiple sets of pencils to be considered.

2. **Premise 2:** Each pack contains 4 pencils.
   - This provides information about the quantity within each individual set (pack).

3. **Premise 3:** Faye places her pencils into rows with 2 pencils per row.
   - This specifies how the pencils are arranged and the size of each row.

Now, let's combine these premises to determine how many complete rows Faye can form:

4. **Calculation:**
   - Total number of pencils = Number of packs × Pencils per pack
     \[
     \text{Total number of pencils} = 35 \times 4 = 140
     \]
   
   - Number of rows = Total number of pencils ÷ Pencils per row
     \[
     \text{Number of rows} = 140 ÷ 2 = 70
     \]

Therefore, Faye can make 70 rows of pencils.

The answer is: 70
