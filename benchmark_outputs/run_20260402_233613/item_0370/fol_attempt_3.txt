## FACTS
1. Paul initially had 50 books.
   - Fact-1: \( P = 50 \)

2. After purchasing some books at a garage sale, Paul ended up with 151 books.
   - Fact-2: \( P + B = 151 \)

## RULES
1. Addition Rule: For any two numbers A and B, if A = C and B = D, then A + B = C + D.
2. Identity Property of Addition: For any number N, N + 0 = N.
3. Commutative Property of Addition: For any two numbers A and B, A + B = B + A.

## INFERENCES
From Fact-2:
\[ P + B = 151 \]

Since \( P = 50 \):
\[ 50 + B = 151 \]

Using the Addition Rule:
\[ B = 151 - 50 \]
\[ B = 101 \]

Therefore, Paul bought 101 books at the garage sale.
