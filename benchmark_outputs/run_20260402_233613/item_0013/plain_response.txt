To determine how many packs of DVDs you can buy with $104 when each pack costs $26, follow these steps:

1. **Identify the total amount of money available:** 
   - Total money = $104

2. **Identify the cost per item (DVD):**
   - Cost per DVD = $26

3. **Calculate the number of items that can be bought:**
   - Number of DVDs = Total money ÷ Cost per DVD
   - Number of DVDs = $104 ÷ $26

4. **Perform the division:**
   - Number of DVDs = 4

Therefore, the answer is: The answer is: 4.
