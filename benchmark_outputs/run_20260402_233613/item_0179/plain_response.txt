To determine how many eggs each group will have, we need to follow these steps:

1. **Identify the total number of eggs**: Rebecca has 8 eggs.
2. **Determine the number of groups**: Rebecca wants to split the eggs into 4 groups.
3. **Calculate the number of eggs per group**:
   - We divide the total number of eggs by the number of groups:
     \[
     \frac{8 \text{ eggs}}{4 \text{ groups}} = 2 \text{ eggs per group}
     \]

Thus, each group will have 2 eggs. The answer is: 2.
