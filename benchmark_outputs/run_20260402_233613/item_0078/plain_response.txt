To determine how many more green peaches than red peaches are in the basket, we need to follow these steps:

1. Identify the number of green peaches.
2. Identify the number of red peaches.
3. Subtract the number of red peaches from the number of green peaches.

Let's go through each step:

1. The number of green peaches is given as 8.
2. The number of red peaches is given as 7.
3. To find out how many more green peaches there are than red peaches, subtract the number of red peaches from the number of green peaches:
   \[
   8 - 7 = 1
   \]
