To determine how many crackers each friend ate, we need to divide the total number of crackers by the number of friends Matthew has.

Given:
- Total number of crackers = 36
- Number of friends = 18

We use division to find out how many crackers each friend gets:

\[ \text{Number of crackers per friend} = \frac{\text{Total number of crackers}}{\text{Number of friends}} \]

Substitute the given values into the equation:

\[ \text{Number of crackers per friend} = \frac{36}{18} \]

Perform the division:

\[ \text{Number of crackers per friend} = 2 \]

So, each person ate 2 crackers.

The answer is: 2
