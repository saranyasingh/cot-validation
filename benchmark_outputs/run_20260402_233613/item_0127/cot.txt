Premise 1: Matthew has given out an equal number of crackers to all of his 18 friends.
Premise 2: Matthew started with 36 crackers.
Premise 3: We need to determine how many crackers each friend ate.

The conclusion:
Each friend ate 2 crackers.

Logical Syllogism:

1. Premise 1 states that Matthew distributed an equal amount of crackers among his 18 friends. This implies that if we divide the total number of crackers (36) by the number of people receiving them (18), each person would receive the same number of crackers.
   
   Therefore,
   \[
   \frac{36}{18} = 2
   \]

Thus, each person ate 2 crackers.

The answer is: Each person ate 2 crackers.
