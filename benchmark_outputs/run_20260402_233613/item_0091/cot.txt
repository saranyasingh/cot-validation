Let's break down this problem using a logical syllogism:

1. **Premise 1**: "He has 9 apples more than Adam and Jackie together."
   - This means if we denote the number of apples Adam has as A and the number of apples Jackie has as J, then He has \(A + J + 9\) apples.

2. **Premise 2**: "Adam and Jackie have 7 apples between them."
   - Therefore, \(A + J = 7\).

3. **Step-by-Step Reasoning**:
   - From Premise 2, substitute \(A + J\) into Premise 1.
     \[
     \text{He has } (A + J) + 9 \text{ apples}
     \]
   - Since \(A + J = 7\), replace \(A + J\) with 7.
     \[
     \text{He has } 7 + 9 \text{ apples}
     \]
   - Perform the addition.
     \[
     \text{He has } 16 \text{ apples}
     \]

4. **Conclusion**:
   - The total number of apples He has is 16.
