Let's break down this problem into a series of logical steps:

1. **Initial Observation**: Rachel initially picked 7 apples from her tree.
   - This statement is given directly and doesn't require any additional premises.

2. **Apples Grown Later**:
   - After picking the 7 apples, 2 more apples grew on the tree.
   - This implies that the number of apples increased after the initial pick-up.

3. **Current Count**: The total number of apples on the tree now is stated as 6.
   - We need to determine how many apples were there originally before these events occurred.

4. **Setting Up Equations**:
   - Let \( x \) represent the original number of apples on the tree.
   - After picking 7 apples, we subtract those from the original count: \( x - 7 \).
   - Then, since 2 more apples grow, we add those back: \( (x - 7) + 2 \).

5. **Given Information**:
   - The current total number of apples on the tree is 6.
   - Therefore, we set up the equation based on the above process:
     \[
     (x - 7) + 2 = 6
     \]

6. **Solving the Equation**:
   - Simplify the left side of the equation:
     \[
     x - 7 + 2 = 6
     \]
     \[
     x - 5 = 6
     \]
   - Add 5 to both sides to isolate \( x \):
     \[
     x = 6 + 5
     \]
     \[
     x = 11
     \]

Thus, the tree had 11 apples to begin with.

The answer is: 11
