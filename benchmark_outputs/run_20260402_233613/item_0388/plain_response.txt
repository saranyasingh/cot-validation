To determine how many action figures Jerry added to the shelf, we can set up an equation based on the information given:

Let \( x \) be the number of action figures Jerry added to the shelf.

Initially, Jerry had 7 action figures on the shelf.
He then added \( x \) action figures.
He removed 10 of the old ones.

After these changes, the total number of action figures on the shelf is 8.

So, the equation representing this situation is:
\[ 7 + x - 10 = 8 \]

Now, let's solve for \( x \):
1. Combine like terms on the left side of the equation:
   \[ 7 - 10 + x = 8 \]
   \[ -3 + x = 8 \]

2. Add 3 to both sides to isolate \( x \):
   \[ -3 + 3 + x = 8 + 3 \]
   \[ x = 11 \]

Therefore, the number of action figures Jerry added to the shelf is 11. The answer is: 11.
