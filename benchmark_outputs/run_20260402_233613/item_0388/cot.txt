Let's break down this problem using a logical syllogism:

Premise 1:
- Jerry originally had 7 action figures on the shelf.
- He later added some new action figures to the shelf.
- He then removed 10 of the old action figures.

Premise 2:
- After these actions, there are 8 action figures left on the shelf.

We need to determine how many action figures Jerry added to the shelf initially.

**Step-by-step Logical Reasoning:**

1. Let \( x \) represent the number of action figures Jerry added to the shelf.
2. Initially, there were 7 action figures on the shelf.
3. After adding \( x \) new action figures, the total became \( 7 + x \).
4. Then, Jerry removed 10 of those action figures.
5. We know that after all these changes, there are 8 action figures remaining on the shelf.

Now we set up an equation based on the information given:

\[ (7 + x) - 10 = 8 \]

Solving this equation:

\[ 7 + x - 10 = 8 \]
\[ x - 3 = 8 \]
\[ x = 8 + 3 \]
\[ x = 11 \]

Therefore, the number of action figures Jerry added to the shelf is **11**.
