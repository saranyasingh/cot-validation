To determine how many more blocks Randy used to build the house compared to the tower, we need to follow these steps:

1. **Identify the total number of blocks used for both projects:**
   - Blocks used for building the house: \( 89 \)
   - Blocks used for building the tower: \( 63 \)

2. **Calculate the difference between the two quantities:**
   To find out how many more blocks were used for the house compared to the tower, subtract the number of blocks used for the tower from the number of blocks used for the house:
   \[
   89 - 63 = 26
   \]

Thus, Randy used \( 26 \) more blocks to build the house than he did to build the tower.

**Conclusion:** The answer is: 26.
