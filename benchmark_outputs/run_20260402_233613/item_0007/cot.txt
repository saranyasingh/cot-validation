1. **Identify the total number of blocks Randy used for both projects:** 
   - Total blocks = Blocks used for house + Blocks used for tower

2. **Calculate the number of blocks used for the house:**
   - Number of blocks used for house = 20

3. **Calculate the number of blocks used for the tower:**
   - Number of blocks used for tower = 50

4. **Subtract the number of blocks used for the house from the total number of blocks used for both projects to find out how many more blocks were used for the tower:**

   \[
   \text{Difference} = \text{Number of blocks used for tower} - \text{Number of blocks used for house}
   \]

   \[
   \text{Difference} = 50 - 20 = 30
   \]
