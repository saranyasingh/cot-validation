To determine how many white t-shirts are in each package, we need to divide the total number of white t-shirts by the number of packages bought. Here's the calculation:

Total number of white t-shirts = 70
Number of packages = 14

Number of t-shirts per package = Total number of t-shirts / Number of packages
Number of t-shirts per package = 70 / 14

Now let's perform the division:
70 ÷ 14 = 5

Therefore, each package contains 5 white t-shirts. The answer is: 5.
