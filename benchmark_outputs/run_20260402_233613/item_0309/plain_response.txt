To determine how many more red peaches than yellow peaches are in the basket, we need to subtract the number of yellow peaches from the number of red peaches:

Number of red peaches = 19
Number of yellow peaches = 11

Difference = Number of red peaches - Number of yellow peaches
           = 19 - 11
           = 8

Therefore, there are 8 more red peaches than yellow peaches in the basket. The answer is: 8.
