To determine how many nails John needs for the house walls, we can follow these steps:

### Premise 1:
- Large planks of wood are used as the primary structure for the house walls.
- This implies that each plank requires some form of attachment or reinforcement.

### Premise 2:
- To secure each plank, John uses 2 pieces of nails.

### Premise 3:
- John plans to use 16 planks for the house walls.

### Conclusion:
Given that each plank needs 2 pieces of nails, we can calculate the total number of nails needed by multiplying the number of planks by the number of nails per plank.

#### Logical Syllogism:

1. **Premise**: Each plank requires 2 pieces of nails (n).
2. **Premise**: John plans to use 16 planks (p).

We need to find out how many nails (N) are required in total.

**Step-by-step Calculation**:
\[ N = p \times n \]
\[ N = 16 \times 2 \]
\[ N = 32 \]

Thus, John needs **32 nails** for the house walls.

The answer is: **32 nails**.
