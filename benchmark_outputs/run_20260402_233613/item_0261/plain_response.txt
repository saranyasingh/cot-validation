To determine how many cakes the baker would still have after selling some, we need to follow these steps:

1. Start with the initial number of cakes.
2. Subtract the number of cakes sold from the initial number of cakes.

Given:
- Initial number of cakes = 167
- Number of cakes sold = 108

Calculation:
167 - 108 = 59

Therefore, the baker would still have 59 cakes. 

The answer is: 59
