To determine how many days it took to harvest the oranges, we can use the information given:

- Total number of sacks of oranges harvested = 54 sacks
- Number of sacks harvested per day = 18 sacks

We need to find the number of days (\(d\)) it took to harvest all the oranges. We can set up the equation as follows:

\[ \text{Total sacks} = \text{Number of sacks per day} \times \text{Number of days} \]

Substituting the known values into the equation:

\[ 54 = 18 \times d \]

To solve for \(d\), divide both sides of the equation by 18:

\[ d = \frac{54}{18} \]
\[ d = 3 \]

Therefore, it took 3 days to harvest all the oranges. The answer is: 3.
