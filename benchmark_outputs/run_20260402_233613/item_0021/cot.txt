To determine how many days it took to harvest the oranges, we need to follow these steps:

1. **Identify the total number of sacks of oranges harvested:** 
   - Total sacks = 54

2. **Determine the rate at which oranges were harvested per day:**
   - Sacks per day = 18

3. **Calculate the total number of days required to harvest all the sacks using the formula:**
   \[
   \text{Total Days} = \frac{\text{Total Sacks}}{\text{Sacks Per Day}}
   \]

4. **Substitute the known values into the formula:**
   \[
   \text{Total Days} = \frac{54}{18}
   \]

5. **Perform the division:**
   \[
   \frac{54}{18} = 3
   \]

Therefore, it took 3 days to harvest all the oranges.

The answer is: 3 days
