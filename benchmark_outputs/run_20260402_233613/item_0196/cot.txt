To determine how many more games Katie has compared to her friends, we need to follow these steps:

1. **Calculate the total number of games Katie has:**
   - Katie has 57 new games.
   - Katie also has 39 old games.
   - Total number of games Katie has = New games + Old games
   \[
   57 + 39 = 96
   \]

2. **Determine the number of games Katie's friends have:**
   - Katie's friends have 34 new games.

3. **Find out how many more games Katie has than her friends:**
   - Subtract the number of games Katie's friends have from the total number of games Katie has.
   \[
   96 - 34 = 62
   \]

**Conclusion:** 
Katie has 62 more games than her friends. 

The answer is: 62
