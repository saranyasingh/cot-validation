To determine how many seats are in each bus, we need to follow these steps:

1. Calculate the total number of seats available for the field trip.
2. Divide this total by the number of buses to find out how many seats are in each bus.

Step 1: Calculate the total number of seats available for the field trip.
- Each classroom can accommodate 30 students (since there are 21 classrooms).
- Therefore, the total number of seats is \( 21 \text{ classrooms} \times 30 \text{ seats/classroom} = 630 \text{ seats} \).

Step 2: Divide the total number of seats by the number of buses.
- There are 7 buses, so we divide the total number of seats by 7: \( 630 \div 7 = 90 \).

Therefore, the number of seats in each bus is 90.

The answer is: 90
