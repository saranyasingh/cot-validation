To determine how many bookshelves Bryan has, we can follow these steps:

1. **Identify the number of books per shelf**: Each bookshelf contains 2 books.
2. **Total number of books**: Bryan has a total of 38 books.
3. **Calculate the number of shelves**:
   - Divide the total number of books by the number of books each shelf holds to find out how many full shelves there are.
   \[
   \text{Number of shelves} = \frac{\text{Total number of books}}{\text{Books per shelf}}
   \]
   \[
   \text{Number of shelves} = \frac{38}{2}
   \]
   \[
   \text{Number of shelves} = 19
   \]

Therefore, Bryan has 19 bookshelves. The answer is: 19.
