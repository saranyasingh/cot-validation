To determine how many Nintendo games Kelly needs to give away so that she will have 12 Nintendo games left, we can follow these steps:

1. Start with the total number of Nintendo games Kelly currently has.
   - Kelly has 20 Nintendo games initially.

2. Let \( x \) be the number of Nintendo games Kelly needs to give away.
3. After giving away \( x \) Nintendo games, Kelly should have 12 Nintendo games remaining.
4. Set up an equation to represent this situation:
   \[
   20 - x = 12
   \]

5. Solve for \( x \):
   \[
   20 - 12 = x
   \]
   \[
   x = 8
   \]

Therefore, Kelly needs to give away 8 Nintendo games so that she will have 12 Nintendo games left. The answer is: 8
