To determine how many students are in each class, we need to follow these steps:

1. **Calculate the total number of students**:
   - We know there are 24 classrooms.
   - Each classroom has an equal number of students.
   - Therefore, the total number of students can be found by multiplying the number of classrooms by the number of students per classroom.

\[ \text{Total number of students} = 24 \times \text{(number of students per classroom)} \]

2. **Determine the number of students per classroom**:
   - Given that the total number of students is 120 and there are 24 classrooms.
   - To find the number of students per classroom, divide the total number of students by the number of classrooms.

\[ \text{Number of students per classroom} = \frac{\text{Total number of students}}{24} \]

3. **Perform the calculation**:
   - Substitute the given values into the formula for the total number of students.

\[ \text{Total number of students} = 24 \times x \]
   - Here \(x\) represents the number of students per classroom.

\[ \text{Total number of students} = 24 \times 5 \]

\[ \text{Total number of students} = 120 \]

- Now calculate the number of students per classroom using the result from step 2.

\[ \text{Number of students per classroom} = \frac{120}{24} \]

\[ \text{Number of students per classroom} = 5 \]

Therefore, the answer is: 5.
