Let's break down the information given:

- Julia played tag with a total of 18 kids.
- She played with 4 kids on Monday.
- We need to find out how many kids she played with on Tuesday.

We can set up an equation to solve this problem:
Total number of kids = Number of kids on Monday + Number of kids on Tuesday

Plugging in the known values:
18 = 4 + Number of kids on Tuesday

Now we can solve for the number of kids on Tuesday:
Number of kids on Tuesday = Total number of kids - Number of kids on Monday
Number of kids on Tuesday = 18 - 4
Number of kids on Tuesday = 14

Therefore, Julia played with 14 kids on Tuesday. 

The answer is: 14
