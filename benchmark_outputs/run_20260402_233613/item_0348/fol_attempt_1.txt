### Facts
These represent the initial premises without quantification.

```plaintext
FACT-1: Matthew has some crackers. :: Cracker(x)
```

```plaintext
FACT-2: Matthew gives 2 crackers to each friend. :: Friend(friend_number)
```

```plaintext
FACT-3: Matthew has 11 friends. :: FriendCount(11)
```

### Rules
These represent universally quantified implications based on the premises.

```plaintext
RULE-1: If Matthew gives crackers to a friend, then he gives 2 crackers to that friend. :: ∀f (Friend(f) → Cracker(x))
```

```plaintext
RULE-2: Matthew cannot have more crackers than what he gave away. :: ∀m (Cracker(m) → ∃g (Friend(g) ∧ Cracker(g)))
```

### Inferences
These derive new conclusions from the facts and rules.

```plaintext
INF-1: Matthew originally had 22 crackers. :: ∀m (Cracker(m) → Cracker(original_crackers))
```
