To determine how many animals were not hiding in the cage, we need to follow these steps:

1. Identify the total number of animals in the cage.
   - Total number of animals = 79

2. Determine the number of snakes that were hiding.
   - Number of snakes hiding = 24

3. Determine the number of alligators that were hiding.
   - Number of alligators hiding = 51

4. Calculate the number of animals that were hiding in total.
   - Number of animals hiding = Number of snakes hiding + Number of alligators hiding
     = 24 + 51
     = 75

5. Subtract the number of hidden animals from the total number of animals to find out how many were not hiding.
   - Number of animals not hiding = Total number of animals - Number of animals hiding
     = 79 - 75
     = 4

Therefore, the number of animals that were not hiding in the cage is 4.

The answer is: 4
