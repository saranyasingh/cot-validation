Rule-1: Number of snakes not hiding = Total number of animals - Number of snakes hiding :: S' = 79 - 24
Rule-2: Number of alligators not hiding = Total number of animals - Number of alligators hiding :: A' = 79 - 51

INF-2: The number of alligators not hiding is 28 :: A' = 79 - 51
