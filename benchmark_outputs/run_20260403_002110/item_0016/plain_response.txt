To determine how many rows Faye can make, we need to follow these steps:

1. Calculate the total number of pencils Faye has.
2. Determine how many rows can be made with the total number of pencils, given that each row contains 2 pencils.

Step 1: Calculate the total number of pencils.
- Faye has 35 packs of pencils.
- Each pack contains 4 pencils.
So, the total number of pencils is \( 35 \times 4 = 140 \) pencils.

Step 2: Determine how many rows can be made.
- Each row contains 2 pencils.
Therefore, the number of rows is \( \frac{140}{2} = 70 \).

The answer is: 70.
