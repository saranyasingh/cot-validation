To find the total number of peaches in all the baskets, we need to calculate the number of peaches per basket first, then multiply that by the total number of baskets.

Given:
- Each basket contains 19 red peaches + 4 green peaches = 23 peaches.
- There are 15 such baskets.

Total peaches in one basket = 23
Number of baskets = 15

Total peaches in all baskets = Total peaches in one basket * Number of baskets
= 23 * 15

Now let's do the multiplication:

23 * 15 = 345

Therefore, the answer is: 345.
