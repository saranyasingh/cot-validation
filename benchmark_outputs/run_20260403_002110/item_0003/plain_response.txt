Let's denote the cost of one book as \( x \). Since Edward bought 2 books and spent a total of $6, we can set up the equation:

\[ 2x = 6 \]

To find the value of \( x \), we divide both sides of the equation by 2:

\[ x = \frac{6}{2} \]
\[ x = 3 \]

So, each book costs $3.

Therefore, the answer is: Each book cost $3.
