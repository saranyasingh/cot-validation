To determine how many days it took to harvest the oranges, we can use the information given:

- Total number of sacks of oranges harvested = 54
- Number of sacks harvested per day = 18

We need to find the total number of days required to harvest all the oranges. This can be calculated using the formula:
\[ \text{Number of days} = \frac{\text{Total number of sacks}}{\text{Sacks per day}} \]

Substituting the given values into the formula:
\[ \text{Number of days} = \frac{54}{18} = 3 \]

Therefore, it took 3 days to harvest all the oranges. 

The answer is: 3
