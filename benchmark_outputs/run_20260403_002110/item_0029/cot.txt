Let's break down this problem using a logical syllogism:

1. **Premise 1:** Zachary did 44 push-ups.
   - This establishes the number of push-ups Zachary performed.

2. **Premise 2:** David did 58 more push-ups than Zachary.
   - From Premise 1, we know Zachary did 44 push-ups.
   - Therefore, to find out how many push-ups David did, we add 58 to the number of push-ups Zachary did:
     \[
     \text{Number of push-ups David did} = 44 + 58 = 102
     \]

3. **Conclusion:** To find the total number of push-ups that both Zachary and David did together, we add their individual totals:
   \[
   \text{Total push-ups} = \text{Push-ups Zachary did} + \text{Push-ups David did}
   \]
   Substituting the values we have:
   \[
   \text{Total push-ups} = 44 + 102 = 146
   \]

**Answer:** The total number of push-ups that Zachary and David did altogether is 146.
