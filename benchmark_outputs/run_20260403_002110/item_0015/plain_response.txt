To find out how many points Melissa scored in each game, we need to divide her total points by the number of games she played.

Total points = 91
Number of games = 13

Points per game = Total points / Number of games
Points per game = 91 / 13

Now let's perform the division:

91 ÷ 13 ≈ 7

So, Melissa scored approximately 7 points in each game.
