Let's break down this problem into a clear logical structure using a syllogism:

**Premise 1:** Melissa scored a total of 91 points in 13 games.
- This establishes the total number of points and the number of games played.

**Premise 2:** She scored the same amount of points in each game.
- This indicates that her average score per game should be constant.

**Conclusion:** Let \( x \) represent the number of points Melissa scored in each game.
- We need to find \( x \).

**Step-by-step Logical Reasoning:**

1. **Total Points Calculation:**
   - Since there were 13 games and the total points scored was 91,
   \[
   13x = 91
   \]

2. **Solving for \( x \):**
   - To find \( x \), divide both sides of the equation by 13:
   \[
   x = \frac{91}{13}
   \]

3. **Performing the Division:**
   - Calculate the division:
   \[
   x = 7
   \]

4. **Verification:**
   - Check if \( x = 7 \) satisfies all conditions:
     - Total points: \( 13 \times 7 = 91 \)
     - Consistent score in each game (since it matches our calculation)

Therefore, the answer is: 
The answer is: 7

This conclusion is derived directly from dividing the total points by the number of games played, ensuring consistency across all games.
