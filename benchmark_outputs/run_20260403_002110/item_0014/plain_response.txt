To determine how many more books than action figures Jerry has on his shelf, we need to follow these steps:

1. Calculate the total number of action figures Jerry now has.
   - Initially, Jerry had 3 action figures.
   - He later added 2 more action figures.
   - Total action figures = Initial action figures + Additional action figures
   - Total action figures = 3 + 2 = 5

2. Determine the difference between the number of books and the number of action figures.
   - Number of books = 7
   - Number of action figures = 5
   - Difference = Number of books - Number of action figures
   - Difference = 7 - 5 = 2

Therefore, there are 2 more books than action figures on his shelf.

The answer is: 2
