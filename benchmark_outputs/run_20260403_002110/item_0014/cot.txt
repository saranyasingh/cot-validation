1. **Premise**: Jerry initially had 7 books.
   - This establishes the starting point for our calculation involving books.

2. **Premise**: Jerry also had 3 action figures.
   - This provides us with another set of numbers that we need to compare later.

3. **Premise**: Jerry then added 2 more action figures to the shelf.
   - This introduces an additional number into our comparison, specifically the total number of action figures after the addition.

4. **Calculation**:
   - To find out how many more books than action figures Jerry has, we first determine the new total number of action figures.
     \[
     \text{Total action figures} = 3 + 2 = 5
     \]
   - Now, we subtract the number of books from this total to find the difference between the number of books and the number of action figures.
     \[
     \text{Difference} = \text{Number of books} - \text{Total action figures}
     \]
     Substituting the known values:
     \[
     \text{Difference} = 7 - 5 = 2
     \]

5. **Conclusion**: Jerry has 2 more books than action figures on his shelf.

The answer is: 2
