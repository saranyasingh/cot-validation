To solve this problem, we need to determine how many grades there are given that each grade has an equal number of students and the total number of students is 270.

Given:
- Total number of students = 270
- Number of students per grade = 5

We can find the number of grades by dividing the total number of students by the number of students per grade:

\[ \text{Number of grades} = \frac{\text{Total number of students}}{\text{Number of students per grade}} \]

Substitute the given values into the formula:

\[ \text{Number of grades} = \frac{270}{5} \]

Now, perform the division:

\[ \text{Number of grades} = 54 \]

Therefore, the answer is: 54.
