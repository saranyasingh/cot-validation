FACT-1: The book has 594 pages in total :: TotalPages(594)
FACT-2: The book has 3 chapters :: NumberOfChapters(3)
FACT-3: Each chapter has the same number of pages :: SamePageCountPerChapter

## RULES
RULE-1: If a book has a total page count and a number of chapters and each chapter has the same number of pages, then the pages per chapter equals total pages divided by number of chapters :: ∀p ∀c (TotalPages(p) ∧ NumberOfChapters(c) ∧ SamePageCountPerChapter → PagesPerChapter(p ÷ c))

## INFERENCES
INF-1: From FACT-1, FACT-2, FACT-3, and RULE-1 by Universal Instantiation and Modus Ponens: The pages per chapter is 594 divided by 3 :: PagesPerChapter(594 ÷ 3)
