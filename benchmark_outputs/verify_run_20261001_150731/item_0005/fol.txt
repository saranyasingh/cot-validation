## RULES
RULE-1: If morning feed is a and afternoon feed is b and a+b=c, then total feed is c :: ∀a ∀b ∀c (Feed(morning,a) ∧ Feed(afternoon,b) ∧ Sum(a,b,c) → Feed(total,c))
RULE-2: If daily feed is a and flock size is b and a/b=c, then per-chicken feed is c :: ∀a ∀b ∀c (Feed(daily,a) ∧ Chickens(flock,b) ∧ Divide(a,b,c) → Feed(per_chicken,c))
RULE-3: If morning-per-chicken feed is a and afternoon-per-chicken feed is b and a+b=c, then the morning-afternoon sum feed is c :: ∀a ∀b ∀c (Feed(morning_per_chicken,a) ∧ Feed(afternoon_per_chicken,b) ∧ Sum(a,b,c) → Feed(morning_afternoon_sum,c))
RULE-4: If total feed is a and morning-afternoon sum feed is b and a−b=c, then final meal feed is c :: ∀a ∀b ∀c (Feed(total,a) ∧ Feed(morning_afternoon_sum,b) ∧ Diff(a,b,c) → Feed(final,c))
