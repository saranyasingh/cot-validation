TotalDistance(x, n) — x's cumulative distance traveled so far is n miles

RULE-2: If a train travels n1 miles on one leg and n2 miles on another leg, and n1 plus n2 equals n3, then the train's cumulative distance is n3 :: ∀x∀l1∀l2∀n1∀n2∀n3 (Travels(x,l1,n1) ∧ Travels(x,l2,n2) ∧ Sum(n1,n2,n3) → TotalDistance(x,n3))
RULE-3: If a train's cumulative distance is n1 and it travels n2 more miles on another leg, and n1 plus n2 equals n3, then the train's new cumulative distance is n3 :: ∀x∀l∀n1∀n2∀n3 (TotalDistance(x,n1) ∧ Travels(x,l,n2) ∧ Sum(n1,n2,n3) → TotalDistance(x,n3))
