EXPLANATION

1. **Total Customers**: Billy has 8 customers.
   - This is our starting point.

2. **First 3 Customers**: Each buys 1 DVD.
   - Total DVDs sold to these customers = \(3 \times 1 = 3\).

3. **Next 2 Customers**: Each buys 2 DVDs.
   - Total DVDs sold to these customers = \(2 \times 2 = 4\).

4. **Last 3 Customers**: None buy DVDs.
   - Total DVDs sold to these customers = \(0 \times 3 = 0\).

5. **Summing Up**: To find the total number of DVDs sold, we add up all the individual totals calculated above.
   - Total DVDs sold = \(3 + 4 + 0 = 7\).

**Conclusion**: Billy sold a total of 7 DVDs on Tuesday.

The answer is: 7
