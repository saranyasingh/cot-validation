## VOCABULARY
Predicates:
Value(x, v) — item x has an original (current) value of v
Rate(x, r) — item x has a predicted market increase rate of r
NewValue(x, n) — item x has a new value of n after the predicted increase
Profit(x, p) — item x yields a profit of p
Better(x, y) — purchasing item x is a better profit choice than purchasing item y

Constants:
jewelry, electronic_gadgets, 5000, 8000, 0.025, 0.012, 5125, 8096, 125, 96

## RULES
RULE-1: For any item, its new value equals its original value plus the original value times its predicted increase rate :: ∀x ∀v ∀r ∀n ((Value(x, v) ∧ Rate(x, r) ∧ n = v + v*r) → NewValue(x, n))
RULE-2: For any item, its profit equals its new value minus its original value :: ∀x ∀v ∀n ∀p ((Value(x, v) ∧ NewValue(x, n) ∧ p = n - v) → Profit(x, p))
RULE-3: For any two items, if one has a greater profit than the other, purchasing it is the better choice :: ∀x ∀y ∀p1 ∀p2 ((Profit(x, p1) ∧ Profit(y, p2) ∧ p1 > p2) → Better(x, y))
