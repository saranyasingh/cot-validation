## VOCABULARY
Predicates:
Quantity(x, n) — item x was purchased in quantity n (dozens)
PricePerDozen(x, n) — item x costs n dollars per dozen
Product(a, b, p) — a multiplied by b equals p
Cost(x, n) — the total cost for item x is n dollars
Sum3(a, b, c, s) — a plus b plus c equals s
TotalCost(n) — the total cost of all purchases is n dollars

Constants:
donuts, cupcakes, cheesecakes
3, 68, 204, 2, 80, 160, 6, 55, 330, 794

## RULES
RULE-1: For any item, if it was purchased in quantity n at price m per dozen, and n times m equals p, then the cost of that item is p :: ∀x∀n∀m∀p (Quantity(x,n) ∧ PricePerDozen(x,m) ∧ Product(n,m,p) → Cost(x,p))
RULE-2: If the cost of donuts is a, the cost of cupcakes is b, the cost of cheesecakes is c, and a plus b plus c equals s, then the total cost is s :: ∀a∀b∀c∀s (Cost(donuts,a) ∧ Cost(cupcakes,b) ∧ Cost(cheesecakes,c) ∧ Sum3(a,b,c,s) → TotalCost(s))
