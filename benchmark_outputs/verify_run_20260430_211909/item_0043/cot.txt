EXPLANATION
Let's break down the problem step-by-step using a logical syllogism.

1. **Premise 1:** Grandma Jones baked 5 apple pies.
   - This establishes the total number of pies that were initially available.

2. **Premise 2:** Each pie was cut into 8 pieces.
   - This provides the size of each piece of pie.

3. **Premise 3:** There were 5 pies originally.
   - This directly relates back to the first premise about the number of pies.

4. **Premise 4:** The pies were set out on the buffet table.
   - This explains where the pies were located before any consumption occurred.

5. **Premise 5:** After serving themselves, there were 14 pieces left.
   - This gives us information about how many pieces were not consumed.

6. **Conclusion:** We need to find out how many pieces were taken by the guests.
   - To do this, we subtract the number of pieces left (14) from the total number of pieces originally available (5 pies * 8 pieces per pie).

Therefore, the calculation is as follows:
\[ \text{Total pieces} = 5 \times 8 = 40 \]
\[ \text{Pieces taken} = \text{Total pieces} - \text{Pieces left} = 40 - 14 = 26 \]

Thus, the number of pieces taken by the guests is 26.

The answer is: 26
