EXPLANATION
1. James runs 3 sprints per day.
2. Each sprint is 60 meters long.
3. Therefore, for each day, he runs \(3 \times 60 = 180\) meters.
4. Since he runs this daily, we need to calculate how much he runs in a week (7 days).
5. To find out his weekly running distance, we multiply the daily distance by the number of days in a week: \(180 \times 7\).

Calculation:
\[180 \times 7 = 1260\]

Therefore, the answer is: 1260
