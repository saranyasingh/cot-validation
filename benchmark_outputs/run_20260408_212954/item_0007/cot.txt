To solve this problem, we need to establish relationships between the number of sheep in Toulouse, Charleston, and Seattle based on the given information.

1. **Premise**: Seattle has 20 sheep.
   - This establishes our starting point for counting sheep.

2. **Premise**: Charleston has 4 times as many sheep as Seattle.
   - If Seattle has 20 sheep, then Charleston would have \(4 \times 20 = 80\) sheep.

3. **Premise**: Toulouse has twice as many sheep as Charleston.
   - Since Charleston has 80 sheep, Toulouse would have \(2 \times 80 = 160\) sheep.

Now that we have the number of sheep for each city:
- Seattle: 20 sheep
- Charleston: 80 sheep
- Toulouse: 160 sheep

Next, let's add these numbers together to find out how many sheep they all have together:

\[
\text{Total Sheep} = \text{Seattle's Sheep} + \text{Charleston's Sheep} + \text{Toulouse's Sheep}
\]

Substituting the values:

\[
\text{Total Sheep} = 20 + 80 + 160
\]

Calculating the sum:

\[
\text{Total Sheep} = 260
\]

Therefore, the total number of sheep that Toulouse, Charleston, and Seattle have together is:

**The answer is: 260**
