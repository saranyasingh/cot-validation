To determine the total number of meters James runs in a week, we can break down the problem into smaller steps:

1. Calculate the distance James runs per session:
   - James runs 3 sprints.
   - Each sprint is 60 meters long.
   - Therefore, the distance for one session (one complete set of three sprints) is \( 3 \times 60 = 180 \) meters.

2. Determine the number of sessions per week:
   - James runs this routine 3 times a week.

3. Calculate the total weekly running distance:
   - Since each session covers 180 meters and he has 3 sessions a week,
   - The total weekly distance is \( 180 \times 3 = 540 \) meters.

Therefore, the total meters James runs a week is 540. 

The answer is: 540
