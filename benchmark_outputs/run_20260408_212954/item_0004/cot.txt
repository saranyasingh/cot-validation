To determine how many total meters James runs a week, we need to break down the problem into smaller parts and then combine them.

**Premise 1:** James runs 3 sprints each time.
- Premise Explanation: This establishes that there is a specific frequency of his running regimen.

**Premise 2:** Each sprint is 60 meters long.
- Premise Explanation: This gives us the length of each individual sprint.

**Premise 3:** James runs this 3 times a week.
- Premise Explanation: This provides the duration or interval between repetitions of his exercise routine.

Now, let's calculate the total distance he runs per sprint cycle (one complete set of 3 sprints):

\[ \text{Distance per sprint} = 60 \, \text{meters} \]

Since he runs 3 sprints per cycle:

\[ \text{Distance per cycle} = 3 \times 60 \, \text{meters} = 180 \, \text{meters} \]

Finally, since he repeats this cycle 3 times a week:

\[ \text{Total weekly distance} = 3 \times 180 \, \text{meters} = 540 \, \text{meters} \]

Therefore, the answer is: 540
