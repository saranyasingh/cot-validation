EXPLANATION
To determine how many total meters James runs a week, we need to break down the problem into smaller steps.

1. **Identify the given information:**
   - James runs 3 sprints.
   - Each sprint is 60 meters long.
   - He runs this 3 times a week.

2. **Calculate the distance covered in one sprint:**
   - Since each sprint is 60 meters and he runs it 3 times a week,
   \[
   \text{Distance per sprint} = 60 \text{ meters}
   \]

3. **Calculate the total distance covered in one session (one set of three sprints):**
   - If he runs 3 sprints, then the total distance for one session is:
   \[
   \text{Total distance per session} = 60 \text{ meters/sprint} \times 3 \text{ sprints}
   \]
   \[
   \text{Total distance per session} = 180 \text{ meters}
   \]

4. **Determine how many sessions he has per week:**
   - James runs this routine 3 times a week.

5. **Calculate the total distance for the entire week:**
   - To find the total distance for the week, multiply the total distance per session by the number of sessions per week:
   \[
   \text{Total weekly distance} = 180 \text{ meters/session} \times 3 \text{ sessions/week}
   \]
   \[
   \text{Total weekly distance} = 540 \text{ meters}
   \]

**Conclusion:**
Thus, the total distance James runs a week is 540 meters.

The answer is: 540
