## FACTS
FACT-1: Edward bought two_books :: Bought(edward, two_books)
FACT-2: The total spent on the two books is six_dollars :: Spent(edward, two_books, six_dollars)
FACT-3: The two books cost the same amount each :: PricesAreEqual(two_books)

## RULES
RULE-1: If someone buys a set of books and spends six_dollars on them, and the set has equal prices, then each book costs three_dollars :: ∀e ∀bks ((Bought(e, bks) ∧ Spent(e, bks, six_dollars) ∧ PricesAreEqual(bks)) → PerBookPrice(e, bks, three_dollars))

## INFERENCES
INF-1: From FACT-1, FACT-2, FACT-3, RULE-1 by Modus Ponens: The price per book is three dollars :: PerBookPrice(edward, two_books, three_dollars)
