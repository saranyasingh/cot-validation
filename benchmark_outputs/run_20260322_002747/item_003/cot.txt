1) There are 72 oranges that need to be packed into bags. (Given)
2) Each bag can hold exactly 8 oranges. (Bag capacity)
3) If we use n bags, we can pack at most 8n oranges. (Capacity times number of bags)
4) To pack all 72 oranges, we need 8n ≥ 72. (Feasibility of packing all oranges)
5) Solving for n gives n ≥ 72/8 = 9. (Division)
6) Since n must be an integer number of bags, the smallest possible n is 9. (Integer constraint)
7) Check: 8 × 9 = 72, which matches the total number of oranges exactly. (Verification)
8) Therefore, the farmer needs 9 bags. (Conclusion)

The answer is: 9
