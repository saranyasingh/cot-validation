EXPLANATION
1. Let's denote the number of sheep in Seattle as S.
   Given: S = 20.

2. Since Charleston has 4 times as many sheep as Seattle,
   we can express this relationship as C = 4 * S.

3. We know that Toulouse has twice as many sheep as Charleston,
   so T = 2 * C.

4. Substituting C into the equation for T, we get:
   T = 2 * (4 * S).

5. Simplifying the expression:
   T = 8 * S.

6. Now, since we already know that S = 20, we substitute it back:
   T = 8 * 20.

7. Calculating the result:
   T = 160.

Therefore, the total number of sheep in Toulouse, Charleston, and Seattle together is 160.
