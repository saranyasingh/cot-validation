Predicates:
SheepCount(x, n) — city x has n sheep
TimesAs(x, y, k) — city x has k times as many sheep as city y
Product(a, b, c) — a multiplied by b equals c
TotalSheep(x, y, z, n) — the combined number of sheep in cities x, y and z is n

## RULES
RULE-1: If x has a times as many sheep as y, y has b times as many as z, and a·b = c, then x has c times as many sheep as z :: ∀x ∀y ∀z ∀a ∀b ∀c ((TimesAs(x, y, a) ∧ TimesAs(y, z, b) ∧ Product(a, b, c)) → TimesAs(x, z, c))
RULE-2: If x has k times as many sheep as y, y has n sheep, and k·n = m, then x has m sheep :: ∀x ∀y ∀k ∀n ∀m ((TimesAs(x, y, k) ∧ SheepCount(y, n) ∧ Product(k, n, m)) → SheepCount(x, m))
