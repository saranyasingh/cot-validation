Explanation:
1. James runs 3 sprints each time.
2. Each sprint is 60 meters long.
3. Therefore, in one session (one time), James runs \(3 \times 60 = 180\) meters.
4. Since James runs this session 3 times a week, we need to calculate the total distance he covers in a week.
5. To find out how much he runs in a week, we multiply the distance of one session by the number of sessions per week: \(180 \times 3 = 540\) meters.

Therefore, the answer is: 540.
