EXPLANATION
To find out how many total meters James runs a week, we need to consider two aspects: the number of sprints he runs per week and the distance he covers in each sprint.

1. **Number of Sprints Per Week**: According to the information given, James runs 3 sprints each time.
2. **Distance Covered in Each Sprint**: Each sprint is 60 meters long.

Now, let's calculate the total distance covered in one session (one time) when he runs all his sprints:
\[ \text{Total Distance per Session} = \text{Number of Sprints} \times \text{Distance per Sprint} \]
\[ \text{Total Distance per Session} = 3 \times 60 \]

Next, since he runs this session 3 times a week, we multiply the total distance per session by the number of sessions per week:
\[ \text{Total Distance per Week} = \text{Total Distance per Session} \times \text{Number of Sessions per Week} \]
\[ \text{Total Distance per Week} = (3 \times 60) \times 3 \]

Performing the multiplication:
\[ \text{Total Distance per Week} = 180 \times 3 \]
\[ \text{Total Distance per Week} = 540 \]

Therefore, the total number of meters James runs in a week is 540 meters. 

The answer is: 540
