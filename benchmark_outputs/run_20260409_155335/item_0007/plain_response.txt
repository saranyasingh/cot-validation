To determine how many sheep Toulouse, Charleston, and Seattle have together, we need to follow these steps:

1. **Determine the number of sheep in Seattle**: 
   Seattle has 20 sheep.

2. **Calculate the number of sheep in Charleston**:
   Charleston has 4 times as many sheep as Seattle.
   \[
   \text{Sheep in Charleston} = 4 \times \text{Sheep in Seattle} = 4 \times 20 = 80
   \]

3. **Calculate the number of sheep in Toulouse**:
   Toulouse has twice as many sheep as Charleston.
   \[
   \text{Sheep in Toulouse} = 2 \times \text{Sheep in Charleston} = 2 \times 80 = 160
   \]

4. **Sum up the total number of sheep for all three cities**:
   \[
   \text{Total Sheep} = \text{Sheep in Toulouse} + \text{Sheep in Charleston} + \text{Sheep in Seattle}
   \]
   Substituting the values we calculated:
   \[
   \text{Total Sheep} = 160 + 80 + 20 = 260
   \]

Therefore, the total number of sheep that Toulouse, Charleston, and Seattle have together is \(260\).

The answer is: 260
