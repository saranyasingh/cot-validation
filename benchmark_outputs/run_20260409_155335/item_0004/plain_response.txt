To determine how many total meters James runs in a week, we can break down the problem into smaller steps:

1. Calculate the distance James runs per session:
   - James runs 3 sprints.
   - Each sprint is 60 meters long.
   - Total distance per session = 3 sprints * 60 meters/sprint = 180 meters.

2. Determine the number of sessions James runs in a week:
   - James runs 3 sprints 3 times a week.
   - Number of sessions per week = 3 sprints/session * 3 sessions/week = 9 sessions/week.

3. Calculate the total distance for the entire week:
   - Total distance per week = Distance per session * Number of sessions per week
   - Total distance per week = 180 meters/session * 9 sessions/week = 1620 meters/week.

Therefore, the total meters James runs in a week is 1620 meters.

The answer is: 1620
