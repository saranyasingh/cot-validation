To determine how many more books than action figures Jerry has on his shelf, we need to follow these steps:

1. **Identify initial quantities**:
   - Books: 7
   - Action figures: 3

2. **Add new items**:
   - Jerry adds 2 more action figures to the shelf.
   
3. **Calculate updated number of action figures**:
   \[
   \text{Updated number of action figures} = 3 + 2 = 5
   \]

4. **Determine total number of books and action figures after addition**:
   - Total number of books: 7 (unchanged)
   - Total number of action figures: 5 (from step 3)

5. **Find the difference between the total number of books and action figures**:
   \[
   \text{Difference} = \text{Total number of books} - \text{Total number of action figures}
   \]
   \[
   \text{Difference} = 7 - 5 = 2
   \]

The answer is: 2
