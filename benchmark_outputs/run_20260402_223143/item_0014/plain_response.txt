To determine how many more books than action figures Jerry has on his shelf, we need to follow these steps:

1. Calculate the total number of action figures after adding more.
2. Subtract this new total from the number of books to find the difference.

First, let's add the additional action figures:
- Initially, there were 3 action figures.
- Jerry added 2 more action figures.
- Therefore, the total number of action figures now is \(3 + 2 = 5\).

Next, we subtract the total number of action figures from the number of books:
- Jerry initially had 7 books.
- After adding the action figures, he has 5 action figures.
- The difference between the number of books and action figures is \(7 - 5 = 2\).

So, Jerry has 2 more books than action figures on his shelf.
