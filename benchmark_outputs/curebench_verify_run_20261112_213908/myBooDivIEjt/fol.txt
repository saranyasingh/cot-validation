Describes(o, a) — answer option o describes action a
Appropriate(a, r) — action a is the appropriate response to reaction r
Answer(o) — option o is the correct answer

## RULES
RULE-1: A reaction listed as an adverse effect of a drug indicates a severe adverse event that should be taken seriously :: ∀d∀r (AdverseEffect(d, r) → Severe(r))
RULE-2: For a severe hypersensitivity reaction, discontinuing the drug immediately is the appropriate response :: ∀r (Severe(r) → Appropriate(discontinue, r))
RULE-3: An option describing the appropriate action is the answer :: ∀o∀a∀r ((Describes(o, a) ∧ Appropriate(a, r)) → Answer(o))
RULE-4: An option describing an action that is not appropriate is not the answer :: ∀o∀a∀r ((Describes(o, a) ∧ ¬Appropriate(a, r)) → ¬Answer(o))
