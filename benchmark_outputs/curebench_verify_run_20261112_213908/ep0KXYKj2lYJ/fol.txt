## RULES
RULE-1: A treatment with no active ingredient cannot cause headaches :: ∀g (¬HasActiveIngredient(g) → ¬CausesHeadache(g))
RULE-2: An option describing a group whose treatment cannot cause headaches is not the answer :: ∀o∀g ((Describes(o, g) ∧ ¬CausesHeadache(g)) → ¬Answer(o))
RULE-3: Since some groups can cause headaches, the option "none of the groups" is not the answer :: ∀o∀g∀h ((Describes(o, none_group) ∧ CausesHeadache(g) ∧ g = g) → ¬Answer(o))
RULE-4: An option describing a group that causes headaches and has headache explicitly listed as a side effect is the answer :: ∀o∀g ((Describes(o, g) ∧ CausesHeadache(g) ∧ ExplicitlyListed(g)) → Answer(o))
