## VOCABULARY
Predicates:
Describes(o, c) — answer option o describes storage condition c
Appropriate(c) — storage condition c is appropriate for sterile medications
Damaging(c) — storage condition c risks damaging or contaminating sterile medications
Answer(o) — option o is the correct answer
Preserves(c) — storage condition c preserves the sterile integrity of the medication

option_a, option_b, option_c, option_d, freezer, room_temperature, high_humidity, below_zero

## OPERATIONS

## RULES
RULE-1: A storage condition that risks damaging the sterile medication is not appropriate :: ∀c (Damaging(c) → ¬Appropriate(c))
RULE-2: A storage condition that preserves the medication's integrity is appropriate :: ∀c (Preserves(c) → Appropriate(c))
RULE-3: An option describing an appropriate storage condition is the answer :: ∀o∀c ((Describes(o, c) ∧ Appropriate(c)) → Answer(o))
RULE-4: An option describing an inappropriate storage condition is not the answer :: ∀o∀c ((Describes(o, c) ∧ ¬Appropriate(c)) → ¬Answer(o))
