## VOCABULARY
Predicates:
Holds(s) — state or need s holds
Causes(s1, s2) — state s1 leads to state s2
Describes(o, x) — answer option o describes action or state x
Unsuitable(a, s) — action a contradicts or fails to address state s
Answer(o) — option o is the correct answer

inhibitor_discontinued, slower_metabolism, increased_exposure, dose_increase_needed, decrease_dose, naloxone, discontinue_roxybond, option_a, option_b, option_c, option_d

## RULES
RULE-1: If state s1 holds and leads to s2, then s2 holds :: ∀x∀y (Holds(x) ∧ Causes(x, y) → Holds(y))
RULE-2: An option describing something that holds is the answer :: ∀o∀s (Describes(o, s) ∧ Holds(s) → Answer(o))
RULE-3: An option describing an action unsuitable for a state that holds is not the answer :: ∀o∀a∀s (Describes(o, a) ∧ Unsuitable(a, s) ∧ Holds(s) → ¬Answer(o))
