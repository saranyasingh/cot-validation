To determine how many DVDs Billy sold on Tuesday, we need to break down his sales into parts based on the given information.

1. **First part**: Billy's first 3 customers each bought 1 DVD.
   - Number of DVDs sold = 3 (customers) × 1 (DVD per customer) = 3 DVDs

2. **Second part**: Billy's next 2 customers each bought 2 DVDs.
   - Number of DVDs sold = 2 (customers) × 2 (DVDs per customer) = 4 DVDs

3. **Third part**: Billy's last 3 customers didn't buy any DVDs.
   - Number of DVDs sold = 0 DVDs

Now, let's add up all the DVDs sold:

- Total DVDs sold = 3 DVDs + 4 DVDs + 0 DVDs = 7 DVDs

Therefore, the total number of DVDs Billy sold on Tuesday is 7 DVDs.
