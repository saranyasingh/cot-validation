EXPLANATION
To determine how many total meters James runs in a week, we need to follow these steps:

1. Calculate the total distance James runs per sprint.
2. Multiply that by the number of sprints he runs each time.

Step 1: Calculate the total distance per sprint
- James runs 3 sprints each day.
- Each sprint is 60 meters long.
Therefore, the total distance per sprint is \(3 \times 60\) meters.

Step 2: Multiply the distance per sprint by the number of days
- James runs this routine 3 times a week.
So, the total distance per week is the distance per sprint multiplied by 3.

Calculation:
\[ \text{Total distance per sprint} = 3 \times 60 = 180 \text{ meters} \]
\[ \text{Total distance per week} = 180 \times 3 = 540 \text{ meters} \]

The answer is: 540
