## VOCABULARY
Predicates:
SprintsPerDay(x, n) — x runs n sprints each day
MetersPerSprint(x, n) — each sprint x runs covers n meters
TimesPerWeek(x, n) — x repeats this daily routine n times per week
TotalDistance(x, n) — x runs a total of n meters

Constants:
james, 3, 60, 180, 540

FACT-2: Each sprint is 60 meters long :: MetersPerSprint(james, 60)

## RULES
RULE-1: If x runs n sprints each day of m meters each, and n × m = p, then x runs p meters per day :: ∀x∀n∀m∀p (SprintsPerDay(x,n) ∧ MetersPerSprint(x,m) ∧ Product(n,m,p) → TotalDistance(x,p))
RULE-2: If x runs p meters per day and repeats this routine t times a week, and p × t = r, then x runs r meters per week :: ∀x∀p∀t∀r (TotalDistance(x,p) ∧ TimesPerWeek(x,t) ∧ Product(p,t,r) → TotalDistance(x,r))
