EatsPerDay(x, n) — x eats n eggs per day (in the omelet)
DaysInWeek(n) — there are n days in a week
Weeks(x, n) — x consumes eggs over a period of n weeks
ConsumesEggs(x, n) — x consumes n eggs (over some period)
ConsumesDozens(x, n) — x consumes n dozens of eggs (over some period)

claire, 3, 7, 4, 12, 21, 84

## RULES
RULE-1: If x eats n eggs per day and there are d days in a week, and n times d equals w, then x consumes w eggs per week :: ∀x∀n∀d∀w (EatsPerDay(x,n) ∧ DaysInWeek(d) ∧ Product(n,d,w) → ConsumesEggs(x,w))
RULE-2: If x consumes w eggs per week over a period of k weeks, and w times k equals t, then x consumes t eggs over that period :: ∀x∀w∀k∀t (ConsumesEggs(x,w) ∧ Weeks(x,k) ∧ Product(w,k,t) → ConsumesEggs(x,t))
RULE-3: If x consumes n eggs, and n divided by 12 equals q, then x consumes q dozens of eggs :: ∀x∀n∀q (ConsumesEggs(x,n) ∧ Quotient(n,12,q) → ConsumesDozens(x,q))
