To determine Josh's profit from flipping the house, we need to follow these steps:

1. Calculate the total cost of buying and repairing the house.
2. Determine the new value of the house after the increase due to repairs.
3. Subtract the original purchase price from the new value to find the profit.

Step 1: Total cost calculation
- Cost of the house: $80,000
- Amount spent on repairs: $50,000

Total cost = $80,000 + $50,000 = $130,000

Step 2: New value calculation
The problem states that the repairs increased the value of the house by 150%.

New value = Original value + (Original value * Increase percentage)
          = $80,000 + ($80,000 * 1.50)
          = $80,000 + $120,000
          = $200,000

Step 3: Profit calculation
Profit = New value - Total cost
        = $200,000 - $130,000
        = $70,000

Therefore, the profit Josh made from flipping the house is $70,000. The answer is: 70000.
