EXPLANATION
To determine how many total meters James runs per week, we need to break down the problem into smaller parts and calculate step-by-step.

1. **Identify the given information**: 
   - James runs 3 sprints each day.
   - He runs these sprints 3 times a week.
   - Each sprint is 60 meters long.

2. **Calculate the total distance for one sprint**:
   - Since each sprint is 60 meters, the total distance for one sprint is simply 60 meters.

3. **Determine the total number of sprints per week**:
   - James runs 3 sprints each day.
   - He runs these sprints 3 times a week.
   - Therefore, the total number of sprints per week is \(3 \text{ sprints/day} \times 3 \text{ days/week}\).

4. **Calculate the total meters for all sprints per week**:
   - Total meters = Number of sprints per week × Distance per sprint.
   - Substituting the values: \( (3 \text{ sprints/day} \times 3 \text{ days/week}) \times 60 \text{ meters/sprint} \).

5. **Perform the calculation**:
   - First, multiply the number of sprints per week by the number of days per week: \(3 \times 3 = 9\).
   - Then, multiply this result by the distance per sprint: \(9 \times 60 = 540\).

Therefore, the total meters James runs per week is 540 meters.
