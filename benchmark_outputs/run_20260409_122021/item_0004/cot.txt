EXPLANATION

1. James runs 3 sprints each time.
2. Each sprint is 60 meters long.
3. Therefore, in one session (sprint), James runs \( 3 \times 60 = 180 \) meters.
4. James runs this session 3 times a week.

Now we calculate the total distance he runs in a week:

5. Since he runs 3 sessions per day and there are 7 days in a week,
   \( 3 \text{ sessions/day} \times 7 \text{ days/week} = 21 \text{ sessions/week} \).

6. In each session, he runs 180 meters,
   so in a week, he runs \( 21 \times 180 = 3780 \) meters.

Therefore, the answer is: 3780.
