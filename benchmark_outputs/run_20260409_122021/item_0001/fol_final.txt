### ## RULES
LABEL: Rules ::  
5. If an item has a price, then the value of the item is the price times the quantity :: ∀p q (Price(p, q) → Value(p, q))
6. If Janet sells an item, she earns the value of the item :: ∀s v (Sells(s, v) → Earnings(s, v))

### ## INFERENCES
LABEL: Inferences ::

9. From Fact-3, Rule-1 by Universal Instantiation: The value of the eggs used for baking muffins is 4 * 2 :: Value(EggConsumption(z, 4, z), 2)
