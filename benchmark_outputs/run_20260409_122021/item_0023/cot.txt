EXPLANATION
1. First, we need to determine how many DVDs were sold to the first 3 customers.
   - Each of these customers bought 1 DVD.
   - Therefore, \(3 \times 1 = 3\) DVDs were sold.

2. Next, we calculate the total number of DVDs sold to the next 2 customers.
   - Each of these customers bought 2 DVDs.
   - Therefore, \(2 \times 2 = 4\) DVDs were sold.

3. We then find out how many DVDs were sold to the last 3 customers.
   - These customers didn't buy any DVDs.
   - Therefore, \(0\) DVDs were sold.

4. To get the total number of DVDs sold, we add up all the DVDs sold to each group of customers.
   - Total DVDs sold = DVDs sold to the first group + DVDs sold to the second group + DVDs sold to the third group
   - Total DVDs sold = \(3 + 4 + 0 = 7\)

Therefore, the answer is: 7.
