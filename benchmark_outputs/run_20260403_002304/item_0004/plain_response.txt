To find out how many pages are in each chapter, we need to divide the total number of pages by the number of chapters. 

Given:
- Total number of pages = 594
- Number of chapters = 3

We can calculate the number of pages per chapter as follows:

\[ \text{Pages per chapter} = \frac{\text{Total number of pages}}{\text{Number of chapters}} \]

\[ \text{Pages per chapter} = \frac{594}{3} \]

Now, let's do the division:

\[ \text{Pages per chapter} = 198 \]

Therefore, the answer is: 198.
