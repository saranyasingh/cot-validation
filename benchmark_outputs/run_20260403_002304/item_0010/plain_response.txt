To find out how many books are in each bookshelf when Bryan distributes 34 books equally among 2 bookshelves, we need to perform division.

Given:
Total number of books = 34
Number of bookshelves = 2

We divide the total number of books by the number of bookshelves:

\[ \text{Books per shelf} = \frac{\text{Total number of books}}{\text{Number of bookshelves}} \]

Substituting the given values:

\[ \text{Books per shelf} = \frac{34}{2} \]

Calculating this gives us:

\[ \text{Books per shelf} = 17 \]

So, there are 17 books in each bookshelf. 

The answer is: 17
