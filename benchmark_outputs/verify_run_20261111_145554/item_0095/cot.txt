To solve this problem, we need to follow these steps:

   - Number of rabbits = \( R \)
   - Combined number of pet dogs + cats = \( D + C \) (where \( D \) is the number of dogs and \( C \) is the number of cats).
   - Given that \( R = D + C - 12 \) (since it's twelve less than the combined number of dogs and cats).
   - Number of dogs (\( D \)) = 60.
   - Cats per dog ratio = 2:1.

2. **Calculate the number of cats:**
   Since the ratio of cats to dogs is 2:1, if there are 60 dogs, then there must be twice as many cats:
   \[
   C = 2 \times D = 2 \times 60 = 120
   \]

3. **Calculate the total number of pets:**
   The total number of pets includes both dogs and cats:
   \[
   Total \, pets = D + C = 60 + 120 = 180
   \]

   According to the problem statement, the number of rabbits is twelve less than the combined number of pet dogs and cats:
   \[
   R = D + C - 12
   \]
   Substituting the values of \( D \) and \( C \):
   \[
   R = 60 + 120 - 12 = 178
   \]

5. **Summarize the results:**
   We have calculated that the total number of pets in the neighborhood is 180.
