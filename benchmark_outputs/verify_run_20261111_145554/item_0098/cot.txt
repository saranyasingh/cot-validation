To determine how many tomatoes Freda used, we need to follow these steps:

1. **Determine the total volume of tomatoes needed:** Since Freda's last batch of tomato sauce made 32 ounces of sauce, and she loses half their volume when cooking them into sauce, we first calculate the original volume of the tomatoes before cooking.

   \[
   \text{Original volume} = 2 \times 32 \text{ ounces} = 64 \text{ ounces}
   \]

2. **Calculate the number of cans required:** Each can contains 16 ounces of tomatoes. Therefore, the number of cans needed is:

   \[
   \text{Number of cans} = \frac{\text{Total volume}}{\text{Volume per can}} = \frac{64 \text{ ounces}}{16 \text{ ounces/can}}
   \]

   Simplifying this gives:

   \[
   \text{Number of cans} = 4
   \]

3. **Determine the number of tomatoes per can:** Each can contains 3 tomatoes.

   \[
   \text{Tomatoes per can} = 3 \text{ tomatoes}
   \]

4. **Calculate the total number of tomatoes used:** Multiply the number of cans by the number of tomatoes per can:

   \[
   \text{Total tomatoes} = \text{Number of cans} \times \text{Tomatoes per can} = 4 \times 3
   \]

   Simplifying this gives:

   \[
   \text{Total tomatoes} = 12
   \]

**Explanation:**
- We started by calculating the original volume of tomatoes needed using the information about the sauce volume.
- Then, we determined the number of cans required based on the given volume per can.
- Finally, we calculated the total number of tomatoes used by multiplying the number of cans by the number of tomatoes per can.
