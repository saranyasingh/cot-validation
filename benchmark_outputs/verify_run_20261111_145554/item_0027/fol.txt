## VOCABULARY
Predicates:
Bought(x, i, n) — x bought n units of item i
PricePerUnit(i, p) — the price per unit of item i is p
TotalCost(x, i, c) — x spent total c on item i
TotalSpent(x, s) — x spent total s on all clothing items

Constants:
mishka, shorts, pants, shoes, 3, 16.50, 22.50, 42, 49.50, 67.50, 126, 243

## FACTS
FACT-1: Mishka bought 3 pairs of shorts :: Bought(mishka, shorts, 3)
FACT-2: One pair of shorts costs $16.50 :: PricePerUnit(shorts, 16.50)
FACT-3: Mishka bought 3 pairs of pants :: Bought(mishka, pants, 3)

## OPERATIONS
OP-1: 3 times 16.50 is 49.50 :: Product(3, 16.50, 49.50)
OP-2: 3 times 22.50 is 67.50 :: Product(3, 22.50, 67.50)
OP-3: 3 times 42 is 126 :: Product(3, 42, 126)
OP-4: 49.50 plus 67.50 plus 126 is 243 :: Sum(49.50, 67.50, 126, 243)

## RULES
RULE-1: If x bought n units of item i at price p per unit and n × p = c, then x's total cost for item i is c :: ∀x∀i∀n∀p∀c (Bought(x,i,n) ∧ PricePerUnit(i,p) ∧ Product(n,p,c) → TotalCost(x,i,c))
RULE-2: If x's total costs for three items sum to s, then x's total spending is s :: ∀x∀i1∀i2∀i3∀c1∀c2∀c3∀s (TotalCost(x,i1,c1) ∧ TotalCost(x,i2,c2) ∧ TotalCost(x,i3,c3) ∧ Sum(c1,c2,c3,s) → TotalSpent(x,s))
