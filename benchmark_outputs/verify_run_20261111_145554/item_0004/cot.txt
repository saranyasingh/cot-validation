EXPLANATION
To determine how many total meters James runs in a week, we need to follow these steps:

1. **Identify the components of his weekly running routine**: 
   - James runs 3 sprints.
   - Each sprint is 60 meters long.

2. **Calculate the distance per sprint**:
   - Distance per sprint = 60 meters.

3. **Determine the total number of sprints per week**:
   - Number of sprints per week = 3.

4. **Multiply the distance per sprint by the number of sprints**:
   - Total meters per week = Distance per sprint × Number of sprints per week.
   - Total meters per week = 60 meters/sprint × 3 sprints/week.

5. **Perform the multiplication**:
   - 60 meters/sprint × 3 sprints/week = 180 meters/week.

Therefore, the total number of meters James runs in a week is 180 meters.

The answer is: 180
