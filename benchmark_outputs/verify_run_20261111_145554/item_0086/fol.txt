VacationsPerYear(x, n) — x goes on n vacations per year
YearsPassed(x, n) — n years passed during x's journey
TotalVacations(x, n) — x took a total of n vacations
QuiltBlocks(x, n) — x's quilt has n blocks (one per unique shirt/vacation)

gene, 23, 34, 4, 11, 44

## RULES
RULE-1: If x's age range is from s to e and e − s = n, then n years passed for x :: ∀x∀s∀e∀n (AgeRange(x,s,e) ∧ Difference(e,s,n) → YearsPassed(x,n))
RULE-2: If x goes on n vacations per year, m years passed, and n × m = p, then x took p total vacations :: ∀x∀n∀m∀p (VacationsPerYear(x,n) ∧ YearsPassed(x,m) ∧ Product(n,m,p) → TotalVacations(x,p))
RULE-3: If x took n total vacations, then x's quilt has n blocks :: ∀x∀n (TotalVacations(x,n) → QuiltBlocks(x,n))
