To determine the number of teachers at Dr. Wertz's school, we need to follow these steps:

1. **Determine the number of boys**: We know that there are twice as many boys as girls.
   - Number of girls = 60
   - Therefore, number of boys = 2 * Number of girls = 2 * 60 = 120

2. **Calculate the total student population**:
   - Total students = Number of boys + Number of girls = 120 + 60 = 180

3. **Determine the number of teachers based on the ratio given**:
   - The problem states that there are 5 students per teacher.

4. **Calculate the number of teachers**:
   - Let \( T \) represent the number of teachers.
   - According to the ratio, \( 5T = \text{Total students} \)
   - Substitute the total students into the equation: \( 5T = 180 \)

5. **Solve for \( T \)**:
   - Divide both sides by 5: \( T = \frac{180}{5} \)
   - Calculate the result: \( T = 36 \)

Thus, the number of teachers at Dr. Wertz's school is 36.

**Explanation**
- First, we calculated the number of boys using the given ratio (twice as many boys as girls).
- Then, we found the total student population by adding the number of boys and girls together.
- Next, we used the provided ratio (5 students per teacher) to find out how many teachers were needed to accommodate all the students.
- Finally, we solved the equation to find the exact number of teachers, which turned out to be 36.

Therefore, the answer is: 36.
