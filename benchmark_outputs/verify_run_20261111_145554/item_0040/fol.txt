RULE-3: If x's speed is k times walking's speed, walking's speed is w, and k × w × f equals d, then x's distance is d :: ∀x∀k∀w∀f∀d (SpeedFactor(x, walking, k) ∧ Speed(walking, w) ∧ Product(k,w,f,d) → Distance(x,d))

RULE-5: If x's distance is a, y's distance is b, and a + b equals s, then the total distance is s :: ∀x∀y∀a∀b∀s (Distance(x,a) ∧ Distance(y,b) ∧ Sum(a,b,s) → Distance(total,s))
