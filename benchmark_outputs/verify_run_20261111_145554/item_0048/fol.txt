## RULES
RULE-1: If x costs pct more than y, y's price is n, pct×n = m, and n+m = p, then x's price is p :: ∀x∀y∀pct∀n∀m∀p (PercentMore(x,y,pct) ∧ Price(y,n) ∧ Product(pct,n,m) ∧ Sum(n,m,p) → Price(x,p))
RULE-2: If p spent n dollars on x, x's price is "price", and n ÷ price = count, then p bought count units of x :: ∀p∀x∀n∀price∀count (Spent(p,x,n) ∧ Price(x,price) ∧ Quotient(n,price,count) → Bought(p,x,count))
RULE-3: If p buys twice as many x as y, p bought n of y, and 2×n = m, then p bought m of x :: ∀p∀x∀y∀n∀m (DoubleCount(p,x,y) ∧ Bought(p,y,n) ∧ Product(2,n,m) → Bought(p,x,m))
RULE-4: If p bought n units of x, x's price is "price", and n×price = total, then p spent total on x :: ∀p∀x∀n∀price∀total (Bought(p,x,n) ∧ Price(x,price) ∧ Product(n,price,total) → Spent(p,x,total))
RULE-5: If p spent n on x and m on y, and n+m = t, then p spent t on all ties :: ∀p∀x∀y∀n∀m∀t (Spent(p,x,n) ∧ Spent(p,y,m) ∧ Sum(n,m,t) → Spent(p,all_ties,t))
