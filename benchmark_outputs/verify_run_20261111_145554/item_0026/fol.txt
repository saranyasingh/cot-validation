## RULES
RULE-1: If x's quantity is n and price per unit is m, and n × m = p, then the cost of x is p :: ∀x∀n∀m∀p (Quantity(x,n) ∧ PricePer(x,m) ∧ Product(n,m,p) → Cost(x,p))
RULE-2: If the chicken meal costs a, milk costs b, apples cost c, and a + b + c = s, then the non-pizza items cost s :: ∀a∀b∀c∀s (Cost(chicken_meal,a) ∧ Cost(milk,b) ∧ Cost(apples,c) ∧ Sum(a,b,c,s) → Cost(non_pizza_items,s))
RULE-3: If x paid n total and the non-pizza items cost m, and n − m = r, then the pizza cost is r :: ∀x∀n∀m∀r (Paid(x,n) ∧ Cost(non_pizza_items,m) ∧ Difference(n,m,r) → Cost(pizza,r))
RULE-4: If the pizza cost is n, the price per box is m, and n ÷ m = q, then x ordered q boxes of pizza :: ∀x∀n∀m∀q (Cost(pizza,n) ∧ PricePer(pizza,m) ∧ Quotient(n,m,q) → Boxes(x,q))
