## RULES
RULE-1: If x walked d1 miles in one segment and d2 miles in another segment, their sum is d, and x has spent time t overall, then x has walked distance d in time t :: ∀x∀d1∀t1∀d2∀t2∀d∀t (Walked(x,d1,t1) ∧ Walked(x,d2,t2) ∧ Sum(d1,d2,d) ∧ TimeSpent(x,t) → Walked(x,d,t))
RULE-2: If x walked distance d in time t and d/t = s, then x's speed is s :: ∀x∀d∀t∀s (Walked(x,d,t) ∧ Quotient(d,t,s) → Speed(x,s))
RULE-3: If x's total trail distance is d and x has spent time t, and d − t = r, then x has r miles remaining :: ∀x∀d∀t∀r (TotalDistance(x,d) ∧ TimeSpent(x,t) ∧ Difference(d,t,r) → RemainingDistance(x,r))
RULE-4: If x's total trail distance is d and x has walked distance c in some time t, and d − c = r, then x has r miles remaining :: ∀x∀d∀c∀t∀r (TotalDistance(x,d) ∧ Walked(x,c,t) ∧ Difference(d,c,r) → RemainingDistance(x,r))
RULE-5: If x has r miles remaining, x's goal speed is s, and r/s = t, then x needs to walk r miles in time t :: ∀x∀r∀s∀t (RemainingDistance(x,r) ∧ Speed(x,s) ∧ Quotient(r,s,t) → Walked(x,r,t))
