## VOCABULARY
Predicates:
ConsumesPerDay(x, n) — x consumes n yogurts per day
Days(x, n) — x considers a period of n days
TotalYogurts(x, n) — x consumes a total of n yogurts
SetInfo(n, p) — a set of n yogurts costs p dollars
TotalCost(x, p) — x's total cost is p dollars

terry, 2, 30, 60, 4, 5, 15, 75

## RULES
RULE-1: If x consumes n yogurts per day over d days and n × d = t, then x consumes a total of t yogurts :: ∀x∀n∀d∀t (ConsumesPerDay(x,n) ∧ Days(x,d) ∧ Product(n,d,t) → TotalYogurts(x,t))
RULE-2: If x consumes a total of t yogurts, a set of s yogurts costs p dollars, t ÷ s = k sets, and k × p = c, then x's total cost is c dollars :: ∀x∀t∀s∀p∀k∀c (TotalYogurts(x,t) ∧ SetInfo(s,p) ∧ Quotient(t,s,k) ∧ Product(k,p,c) → TotalCost(x,c))
