## VOCABULARY
Predicates:
Cost(x, n) — glass type x costs n dollars each
Rate(x, y, n) — glass type y's price is n times glass type x's price
Wants(x, n) — x wants to buy n glasses total
Count(x, n) — there are n glasses of type x among those bought
TotalCost(x, n) — the total cost associated with x is n dollars

## RULES
RULE-1: If glass type x costs n dollars and glass type y's price is m times x's price, and m × n = p, then glass type y costs p dollars :: ∀x∀y∀n∀m∀p (Cost(x,n) ∧ Rate(x,y,m) ∧ Product(m,n,p) → Cost(y,p))
RULE-2: If a person wants n glasses total and half of n is h, then there are h glasses of the first type and h glasses of the second type :: ∀x∀n∀h (Wants(x,n) ∧ Quotient(n,2,h) → Count(first_glass,h) ∧ Count(second_glass,h))
RULE-3: If there are n glasses of type x, each costing c dollars, and n × c = t, then the total cost for type x is t dollars :: ∀x∀n∀c∀t (Count(x,n) ∧ Cost(x,c) ∧ Product(n,c,t) → TotalCost(x,t))
RULE-4: If the total cost for type x is t1 dollars and the total cost for type y is t2 dollars, and t1 + t2 = s, then Kylar's total cost is s dollars :: ∀x∀y∀t1∀t2∀s (TotalCost(x,t1) ∧ TotalCost(y,t2) ∧ Sum(t1,t2,s) → TotalCost(kylar,s))
