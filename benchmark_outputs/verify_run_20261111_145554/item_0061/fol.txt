Percent(x, type, p) — the fraction (percent as decimal) of x's oranges of category "type" is p

## RULES
RULE-1: If x has n total oranges and a fraction p of them are of some category, and n×p = u, then the count of that category is u :: ∀x∀n∀p∀u (Count(x,total,n) ∧ Percent(x,unripe,p) ∧ Product(n,p,u) → Count(x,unripe,u))
RULE-2: If x has u unripe oranges and s sour oranges, and u+s = b, then the total bad (unripe+sour) count is b :: ∀x∀u∀s∀b (Count(x,unripe,u) ∧ Count(x,sour,s) ∧ Sum(u,s,b) → Count(x,bad,b))
RULE-3: If x has n total oranges and b bad oranges, and n−b = g, then the count of good oranges is g :: ∀x∀n∀b∀g (Count(x,total,n) ∧ Count(x,bad,b) ∧ Difference(n,b,g) → Count(x,good,g))
