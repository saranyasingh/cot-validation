Consumes(x, n) — x consumes n eggs (for breakfast or baking)
Remaining(x, n) — x has n eggs remaining
PricePerEgg(x, n) — x sells eggs at n dollars each
Earnings(x, n) — x earns n dollars

## RULES
RULE-1: If x lays n eggs per day and consumes k of them, and n − k = r, then x has r eggs remaining :: ∀x∀n∀k∀r (LaysEggs(x,n) ∧ Consumes(x,k) ∧ Difference(n,k,r) → Remaining(x,r))
RULE-2: If x has n eggs remaining and consumes k more, and n − k = r, then x has r eggs remaining :: ∀x∀n∀k∀r (Remaining(x,n) ∧ Consumes(x,k) ∧ Difference(n,k,r) → Remaining(x,r))
RULE-3: If x has n eggs remaining and sells each at price p, and n × p = r, then x earns r dollars :: ∀x∀n∀p∀r (Remaining(x,n) ∧ PricePerEgg(x,p) ∧ Product(n,p,r) → Earnings(x,r))
