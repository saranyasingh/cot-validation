## VOCABULARY
Predicates:
Weighs(y, n) — each unit of item y weighs n pounds
Removes(x, y, n) — x removes n units of item y
NeedsToRemove(x, n) — x needs to remove a total weight of n pounds
TotalWeight(x, y, n) — the total weight of items y that x removes is n pounds

Constants:
uriah, comic_book, toy, 30, 0.25, 0.5, 15, 7.5

## RULES
RULE-1: If x removes n units of y, each y weighs w pounds, and n × w = p, then the total weight of y removed by x is p pounds :: ∀x∀y∀n∀w∀p (Removes(x,y,n) ∧ Weighs(y,w) ∧ Product(n,w,p) → TotalWeight(x,y,p))
RULE-2: If x needs to remove a total weight of n pounds, each unit of y weighs w pounds, and n ÷ w = c, then x must remove c units of y :: ∀x∀y∀n∀w∀c (NeedsToRemove(x,n) ∧ Weighs(y,w) ∧ Quotient(n,w,c) → Removes(x,y,c))
