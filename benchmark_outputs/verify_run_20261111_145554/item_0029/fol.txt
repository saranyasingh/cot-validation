Predicates:
TotalDistance(x, n) — x's total trip distance is n miles
FirstStopLocation(x, n) — x's first stop occurs at n miles into the journey
SecondStopBeforeEnd(x, n) — x's second stop is n miles before the end of the trip
RemainingDistance(x, n) — the remaining distance after x's first stop is n miles
DistanceBetweenStops(x, n) — the distance x traveled between the first and second stops is n miles

henry, 60, 20, 15, 40, 55

## RULES
RULE-1: If x's total trip distance is t and x's first stop is at f miles, and t − f = r, then the remaining distance after the first stop is r :: ∀x∀t∀f∀r (TotalDistance(x,t) ∧ FirstStopLocation(x,f) ∧ Difference(t,f,r) → RemainingDistance(x,r))
RULE-2: If the remaining distance after x's first stop is r and x's second stop is s miles before the end of the trip, and r + s = d, then the distance x traveled between the first and second stops is d :: ∀x∀r∀s∀d (RemainingDistance(x,r) ∧ SecondStopBeforeEnd(x,s) ∧ Sum(r,s,d) → DistanceBetweenStops(x,d))
