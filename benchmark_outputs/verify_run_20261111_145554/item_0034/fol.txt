GoldMoreThanSilver(x, n) — x has n more gold coins than silver coins
Silver(x, n) — x has n silver coins
Gold(x, n) — x has n gold coins

gretchen, 110, 30, 80, 40, 70, 2

## RULES
RULE-1: If x has t coins total, has d more gold than silver coins, t − d = s, and s ÷ 2 = half, then x has half silver coins :: ∀x∀t∀d∀s∀half (TotalCoins(x,t) ∧ GoldMoreThanSilver(x,d) ∧ Difference(t,d,s) ∧ Quotient(s,2,half) → Silver(x,half))
