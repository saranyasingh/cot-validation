## VOCABULARY
Predicates:
EatsPerPerson(x, n) — each individual of type x eats n lbs of potato salad
Count(x, n) — there are n individuals of type x
Total(x, n) — the total amount of potato salad for x is n lbs

Constants:
adult, child, ted, 10, 20, 5, 200, 25, 225, 2

## FACTS
FACT-1: Each adult eats 10 lbs :: EatsPerPerson(adult, 10)
FACT-2: There are 20 adults :: Count(adult, 20)
FACT-3: There are 5 children :: Count(child, 5)

## OPERATIONS
OP-1: 10 divided by 2 is 5 (half as much) :: Quotient(10, 2, 5)
OP-2: 10 times 20 is 200 :: Product(10, 20, 200)
OP-3: 5 times 5 is 25 :: Product(5, 5, 25)
OP-4: 200 plus 25 is 225 :: Sum(200, 25, 225)

## RULES
RULE-1: If each adult eats n lbs and n divided by 2 is m, then each child eats m lbs :: ∀n∀m (EatsPerPerson(adult, n) ∧ Quotient(n, 2, m) → EatsPerPerson(child, m))
RULE-2: If each individual of type x eats n lbs and there are m of them, and n times m is p, then the total for x is p lbs :: ∀x∀n∀m∀p (EatsPerPerson(x, n) ∧ Count(x, m) ∧ Product(n, m, p) → Total(x, p))
RULE-3: If the total for adults is n lbs and the total for children is m lbs, and n plus m is p, then Ted needs to bring p lbs :: ∀n∀m∀p (Total(adult, n) ∧ Total(child, m) ∧ Sum(n, m, p) → Total(ted, p))
