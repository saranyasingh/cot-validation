Predicates:
PlayTime(x, n) — x played ping pong for a total of n minutes
HalfTime(x, h, n) — during half h of the game, x played for n minutes
Score(x, h, n) — during half h of the game, x scored n points
TotalScore(x, n) — x scored n points in total

mike, first, second, 40, 20, 4, 0.25, 1, 5

## RULES
RULE-1: If x scored n points in the first half and n × 0.25 = r, then x scored r points in the second half :: ∀x∀n∀r (Score(x, first, n) ∧ Product(n, 0.25, r) → Score(x, second, r))
RULE-2: If x scored n points in the first half and m points in the second half and n + m = t, then x scored t points in total :: ∀x∀n∀m∀t (Score(x, first, n) ∧ Score(x, second, m) ∧ Sum(n, m, t) → TotalScore(x, t))
